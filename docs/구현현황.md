> **추가(2026-11-05): AI 도면 해석 (Claude API)** — 고객사가 [브랜드·쇼룸]에서 'AI 도면 해석 사용'을 켜고 서버에 `ANTHROPIC_API_KEY` 가 있으면, 2D 도면 업로드 즉시 AI 가 도면 그림(DXF·DWG 는 선을 직접 그린 PNG + CAD 치수 값·위치, PDF·이미지는 1568px 그림 + OCR 숫자)을 보고 제품 종류·부품(상자·외함(shell)·원기둥·관통 구멍)·치수·위치·분해 방향을 돌려주면, 프로그램이 Manifold 로 부품별 3D 를 조립합니다. 치수는 도면에 적힌 숫자 우선, 추정값은 근거 표시. 실패하면 규칙 기반 초안으로 자동 대체. 고객사별 월 한도(기본 300장), 사용량(토큰)은 감사 로그에 기록. 키 하나(운영자)로 모든 고객사가 사용 — 고객은 별도 가입 없음. 테스트 AI-1~3(모의 API 서버) 추가, 전체 26개 통과.

> 추가(2026-11-05): **부품별 자동 분할** — 투상도 안의 선으로 나뉜 영역을 부품 후보로 찾고(닫힌 윤곽 소속·공극 판정·분해된 해칭 제거·중심/숨은/치수 레이어 제외), 측면·평면의 대응 영역과 교차해 부품별 3D. 핀·볼트는 원기둥 추정(위치 = 평면도 숨은선 원). 금형 조립도 12개 부품·분전반 외함도 4개 부품을 정확한 크기로 복원. '외형 한 덩어리' 모드 선택 가능. 테스트 M·M-2·P 추가 (전체 17개 통과).

> **추가(2026-11-05, 핵심 흐름): 2D 도면만 올리면 바로 3D 쇼룸**
> - **업로드 즉시 자동 3D 초안**: 2D 도면(DXF·DWG·PDF·스캔·이미지) 분석이 끝나면 자동으로 '참고용 AI 3D 시각화'(검토 대기) 모델을 만들고 작업 화면에서 바로 엽니다. 투상도 3개가 짝지어지면 결합(Visual Hull), 1개면 판재 돌출. 도면에 없는 값은 **축척: 도면 글자("SCALE 1:2") → 치수 숫자 비교 → 기본값 1:1**, **두께: 도면 글자("t=6", "THK 6", "두께 6") → 외형 짧은 변 5%를 표준 판두께로** 추정하고 근거(도면/AI 추정/기본값)를 표시합니다. 값이 틀리면 [3D 변환]에서 추정값이 미리 채워진 상태로 고쳐 다시 만들 수 있습니다(원래 초안은 남음). `AUTO_DRAFT=false` 로 끌 수 있음.
> - **스캔 PDF·JPG·PNG·TIFF 도면**: 래스터 분석(오츠 이진화·먼지 제거·도곽/구분선 제거·선 틈 메움·바깥 채우기·열림 연산으로 치수선·글자 제거 → 외형, 닫힌 빈 영역 → 구멍, 원형 구멍은 선 중심 반지름 측정) + **Tesseract OCR**(한국어+영어, 배치분석·흩어진 글자 2회). 결과는 벡터 도면과 같은 형식이라 투상도 결합·돌출을 그대로 사용. 스캔 외형은 'AI 추정'으로 표시.
> - **쇼룸 템플릿 7종 + 투명 배경**: 고급 제품 전시관·산업용 기계·금형 기술설명·전자제품·건축물·다크 스튜디오·화이트 스튜디오 (그라데이션 배경, 반사 바닥, 스포트 조명, 그리드). 프로젝트 업종별 기본 템플릿 자동 지정, 작업 화면·공유 화면 툴바에서 전환, MP4 렌더도 같은 템플릿. **그림자가 보이지 않던 문제 수정**(그림자 카메라 범위 갱신 누락·조명 방향).
> - **고객사별 쇼룸**: 회사 브랜드(쇼룸 이름·로고·대표 색상·소개·연락처) 설정(관리자), 공유 화면 머리글·색상에 반영, **고객사 쇼룸 페이지 `/c/<주소>`** — 그 회사가 공개한 제품 전체를 썸네일 카드로(업종 필터, 비밀번호 링크는 썸네일 비공개, 폐기·만료·목록 제외 링크는 빠짐). 모델 썸네일 자동 촬영.
> - 프로그램명 표기를 **EUM 3D SHOWROOM PRO** 로 변경. 테스트 S·S-2·S-3·S-4·T·T-2 추가, H-2 갱신.

> 추가(2026-11-05): **STEP 없이 2D 도면 → 3D 초안 (투상도 결합, 규칙 기반 자동 추정)** — 도면에서 정면·평면(저면)·측면도 자동 인식(실루엣 추출·정렬·칸막이 판정), 투상도 실루엣 교차(Manifold CSG)로 입체 생성, AI 추정 표시·검토 승인. 외부 AI(Claude API) 연결은 미정이라 미구현. 테스트 R 추가 (전체 14개 통과).

- **3단계 AI 도면** (부분 구현: PDF 벡터 분석 ✅, 다중 투상도 인식·투상도 결합 형상 재구성 ✅(규칙 기반), AI 추정 표시·검토 승인 ✅, 스캔·이미지 도면 래스터 분석·OCR ✅, 업로드 즉시 자동 초안 ✅). 미구현: 외부 AI(Claude 비전) 연결, 숨은선·단면도 해석으로 내부 형상 복원, 경사면·곡면(보조 투상도) 해석, 투상도 안의 부품별 분리, 부품 분류·조립 관계 추론, AI 분해 순서, 도면·3D 비교
- **4단계 상용화**: 라이선스 서버·오프라인 라이선스·기능별 라이선스, 사용자 수·용량·렌더 사용량 한도 강제, 화이트라벨(로고·프로그램명·도메인) 화면, 관리자 UI(사용자·감사 로그), 결제·계약, S3 저장소 드라이버, 저장 데이터 암호화(현재 디스크/볼륨 수준에 의존), 백업·보존 정책, 악성코드 엔진(ClamAV) 연동, GPU 렌더 워커 실제 구성, Blender 고품질 렌더
- 미지원 형식: DWF, OBJ·FBX·GLTF(분리형)·3MF·IFC, 네이티브 CAD
- 스캔·이미지 도면: 기울어진 스캔(회전 보정) 없음, 손그림·사진 원근 왜곡 보정 없음, 숨은선(점선)·단면 해칭 해석 없음, 투상도끼리 치수선으로 붙어 있으면 한 덩어리로 인식될 수 있음. OCR 이 축척을 잘못 읽으면 치수 숫자 비교로 보정하지만 숫자가 적으면 기본값(1:1)이 쓰임 — 화면의 근거 표시를 확인해야 함
- 자동 두께 추정은 판재 가정(짧은 변의 약 5%)이라 블록형 부품 단일 투상도에서는 틀릴 수 있음 (검토 대기로 표시)
- PDF: 1쪽만 분석. 곡선 경로 일부(S/A 명령) 근사·생략
- DWG: LibreDWG 기반이라 해치·스플라인·WIPEOUT·동적 블록 등 일부 객체는 빠지거나 근사됨, 외부참조(XREF) 미포함, DWG 내보내기 없음
- 동영상 부가 기능: WebM·GIF·PNG/JPG 시퀀스, 배경음악·음성 설명, 시작/종료 화면, 로고 이미지, 장면 전환 효과, 키프레임 단위 편집(현재는 클립 단위)
- 쇼룸 부가: 거리·각도 측정, 좌표 표시, 다중 단면, 카메라 북마크 여러 개, 다운로드 제한 설정, 제품 문의 폼
- 다국어: 구조와 한국어·영어 일부만, 일본어·중국어 사전 없음 / 언어 선택 UI 없음

## 4. 알려진 제한
- 기본 분해 방향은 기하 중심 기반 제안이며 **부품 간 충돌을 검토하지 않습니다**.
- STL·GLB 의 단위 정보는 신뢰할 수 없어 mm/원본 단위로 표시합니다.
- 서버 렌더는 CPU(SwiftShader) 기준: HD 3초 영상 ≈ 10~20초, Full HD 15초 영상 ≈ 수 분. QHD·4K 는 오래 걸립니다.
- 같은 형상을 공유하는 STEP 인스턴스는 이름이 같게 오므로 "이름 (2)" 형식으로 구분합니다.

## AI 제공자 복수 지원 (Claude + GPT)
- `server/convert/ai.js`: `PROVIDERS`(claude·openai), `aiProviders()` 키 있는 제공자, `resolveProviders()`; `interpretDrawing({provider})` 가 OpenAI(Chat Completions 함수 호출, 이미지 data URL)로도 같은 `build_showroom_model` 명세를 받는다. 형상 생성은 공통.
- 회사 설정 `companies.ai_provider` (claude | openai | both | NULL=서버 기본 `AI_PROVIDER`). [브랜드·쇼룸] 에서 선택, `GET /api/ai/status` 가 `providers`/`provider` 반환.
- `POST /api/files/:id/ai-draft {provider}` — `both` 면 두 AI 를 동시에 호출해 모델 2개("(AI 3D·Claude)", "(AI 3D·GPT)")를 만들고, 점수(윤곽 기반 부품 수·부품 수·scaleRef·정면 비율)가 높은 쪽을 대표(`modelId`)로. 사용량(audit model.aidraft)은 호출 횟수만큼.
- 환경변수 `OPENAI_API_KEY`, `OPENAI_MODEL`(기본 gpt-6.1-sol), `OPENAI_BASE_URL`(테스트용). 테스트 AI-5·AI-6.
