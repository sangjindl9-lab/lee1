개발자: 이음소프트웨어 · 앱: 파일관리자2 (Android) · 파일 관리자 2 PC (Windows)

방법 1. 앱에서 삭제

  1. 파일관리자2 앱을 엽니다.
  2. 홈 화면의 PC 연결을 누릅니다.
  3. 맨 아래 계정 삭제를 누르고 비밀번호를 입력합니다.

방법 2. 이 페이지에서 바로 삭제

비밀번호를 잊으셨다면 pm999@naver.com 으로 가입 이메일 주소에서 삭제를 요청해 주세요. 본인 확인 후 7일 이내에 삭제합니다.

삭제되는 정보 (즉시)

  • 계정 정보: 이메일, 이름, 비밀번호 해시
  • 로그인한 기기 정보와 로그인 세션
  • PC 연결 승인 내역과 허용 폴더 정보
  • 클라우드 연결 정보(암호화된 접근 토큰 — 각 서비스에도 폐기 요청)
  • 내가 만든 공유 링크(즉시 무효)

보관 후 삭제되는 정보

  • 보안 목적의 접근 기록(로그인·연결 시각, IP)과 전송 기록: 최대 1년 보관 후 자동 삭제

휴대폰·PC·클라우드에 있는 사용자의 파일은 삭제되지 않습니다. 서버에는 파일 내용을 저장하지 않습니다.

계정을 지우지 않고 일부 정보만 지우려면: 앱의 PC 연결 화면에서 로그인 기기 로그아웃, PC 연결 해제를 하거나, PC 프로그램에서 클라우드 연결 해제·공유 링크 해제를 하면 해당 정보가 즉시 삭제됩니다.
