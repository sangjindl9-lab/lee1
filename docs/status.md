# 기능별 구현 상태 (Rev 0.1, 1단계)

구분: **구현 완료**(실제 서버·DB·브로커로 시험 통과) · **부분 구현** · **미구현** · **외부 API 필요** · **실제 장비 검증 필요**

## 1단계 — 작동하는 스마트박스 관제

| 기능 | 상태 | 비고 |
| --- | --- | --- |
| 로그인·세션·로그아웃 | 구현 완료 | JWT(HS256) + 세션 테이블(폐기 가능), 로그인 이력 |
| 관리자 다중요소 인증(TOTP) | 구현 완료 | 관리자 역할은 MFA 설정 전 API 차단 |
| 로그인 실패 잠금 | 구현 완료 | 5회 실패 시 15분 |
| 역할 기반 권한(8개 역할, 13개 권한) | 구현 완료 | 관제요원은 조회·확인만, 전원 제어는 별도 역할 |
| 기관(테넌트) 단위 데이터 분리 | 구현 완료 | REST·실시간 채널 모두 시험 |
| 중요 명령 재인증(step-up) | 구현 완료 | 5분 유효, 본인 토큰만 |
| 위험 명령 이중 승인 | 구현 완료 | 공유 장비(PoE 스위치·광컨버터) 차단·재투입, 10분 유효, 본인 승인 불가 |
| 일괄 전원 제어 | 구현 안 함(의도) | 지시서대로 기본 비활성 — API 자체가 없음 |
| 현장·함체·스마트박스 등록 | 구현 완료 | 함체번호·시설물번호·좌표 |
| 장치 프로비저닝(장치별 인증서·명령키) | 구현 완료 | 내부 CA, 비밀정보 1회만 표시 |
| MQTT over TLS + 장치별 인증서(mTLS) | 구현 완료 | 내장 브로커로 시험. Mosquitto 설정 제공(미시험) |
| 명령 ID·ACK·결과·타임아웃·재전송·중복 실행 방지 | 구현 완료 | 장치 측 최근 32건 기억 |
| 명령 무결성(HMAC-SHA256 서명) | 구현 완료 | 서명 불일치 거부 시험 |
| 센서 계측 저장(시계열) | 구현 완료 | TimescaleDB 있으면 하이퍼테이블 자동 전환 |
| 실시간 대시보드(WebSocket) | 구현 완료 | |
| 릴레이 제어(차단·공급·재투입) | 구현 완료 | 시뮬레이터로 검증, 실제 보드 미검증 |
| 장애 알람(발생·중복 묶음·복귀·확인·배정·조치) | 구현 완료 | 등급 긴급/심각/주의/정보 |
| 통신 두절 판정(LWT + 계측 무수신) | 구현 완료 | |
| 제어 감사로그(해시 체인·수정 금지) | 구현 완료 | DB 관리자 권한 변조도 탐지 |
| 데이터 보존정책 | 부분 구현 | 계측·이벤트 기간 삭제. 설정 화면 없음(DB 설정값) |
| 서버 재시작 후 진행 중 명령 복원 | 구현 완료 | |
| DB 백업·복원 | 부분 구현 | 스크립트 제공, pg_dump/pg_restore 정합성 시험 통과. Docker 환경 미시험 |
| Docker Compose 설치 | 부분 구현 | 파일 작성, 이 개발 환경에 Docker 데몬이 없어 미시험 |
| 오프라인 설치 묶음 | 부분 구현 | 스크립트만 작성, 미시험 |
| 화이트라벨(제품명·회사명·로고) | 부분 구현 | 설정값·웹 branding.json. 관리 화면 없음 |
| 라이선스(모드 A/B/C) | 미구현 | 테이블만 있음 |
| 펌웨어(ESP32, SB-MB01) | 실제 장비 검증 필요 | ESP32 툴체인으로 컴파일 성공, 로직 단위시험 197건 통과. 보드 미제작으로 실기 미검증 (firmware/README.md) |
| 펌웨어 독립 제어(통신 두절 시 온도제어·경보·감시·자동복구, 시간당 제한) | 실제 장비 검증 필요 | 로직 단위시험 통과 |
| OTA(서명된 펌웨어 업데이트·복구) | 미구현 | 테이블만 있음 |
| 서버 이중화 | 미구현 | |
| 알림 발송(SMS·알림톡·이메일·푸시) | 미구현 | 외부 API 필요. 내부(화면) 알림만 |
