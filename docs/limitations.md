# 알려진 제한사항 및 미구현 기능

## 광고 차단
- DNS 방식 한계: 콘텐츠와 같은 도메인으로 오는 광고(유튜브 동영상 광고, 앱 내장 광고), 하드코딩된 IP 광고는 차단 불가
- 앱 자체 DoH 사용, Android '개인 DNS' 특정 서버 지정 시 차단 불가 (앱이 감지해 안내)
- 다른 VPN 과 동시 사용 불가 (Android 제한)
- 광고 노출 수는 측정하지 않음 — 통계는 'DNS 요청 차단 건수'
- 앱별 제외를 바꾸면 VPN 을 다시 연결함 (1초 내외)
- 배터리 사용량은 에뮬레이터에서 의미 있게 측정되지 않음 → 실기기 측정 필요
- IPv6 전용망 동작은 에뮬레이터에서 검증하지 못함
- 허용 목록·필터 변경은 DnsLibs 가 전체 필터를 다시 읽은 뒤 적용되어 저사양 기기에서 수 초~20초 걸릴 수 있음
- 강제 종료(설정 > 강제 중지) 시 VPN 도 꺼지며, 사용자가 끈 VPN 을 앱이 임의로 다시 켜지 않음 (Android '상시 VPN' 설정으로 자동 연결 가능)

## 악성코드 검사
- **운영 악성 해시 데이터 미적재**: 현재 DB 의 해시는 테스트용(EICAR, EUM 픽스처)뿐입니다. MalwareBazaar 데이터는 abuse.ch Auth-Key 가 필요해 아직 넣지 못했습니다 (`tools/build_threat_db.py --bazaar` 로 바로 적재 가능).
- YARA 규칙: 상업적으로 쓸 수 있는 공개 Android YARA 규칙을 찾지 못해 자체 휴리스틱 3개 + 테스트 규칙 2개만 있습니다. 자체 휴리스틱은 신뢰도 ≤50 으로 '주의'까지만 냅니다.
- YARA-X 는 64비트(arm64-v8a, x86_64) 기준으로 검증. armeabi-v7a 빌드 결과는 CI 의 rust-abi.txt 참조 — 실패 시 해당 기기는 경량 패턴 엔진으로 대체
- 분할 APK(split APK)는 base.apk 만 검사
- Androguard 서버 심층 분석, ClamAV 보조 검사: 미구현 (선택적 서버 기능, 동의·업로드 화면 포함 필요)
- 정기 검사 결과 알림만 있고, 새로 설치되는 앱 실시간 검사는 없음

## 화면
- 결과 화면의 엔진 이름(예: 'APK 정적 분석 v1')과 일부 업데이트 메시지는 언어 설정과 관계없이 한국어로 표시됨
- Android 10~12 는 앱별 언어 선택을 앱 설정 화면에서만 지원 (시스템 언어 따름)

## 배포
- AAB 의 Play 업로드 키 서명은 GitHub Secrets 등록 후 가능
- 태블릿 스크린샷, 512 아이콘, 대표 이미지 미제작
- 실기기 테스트 미수행 (에뮬레이터 API 29·34 만)
- WorkManager 가 WAKE_LOCK·RECEIVE_BOOT_COMPLETED 권한을 자동 추가함 (정기 업데이트 재예약용, VPN 자동 시작에는 쓰지 않음)
- Google Play 심사 통과는 보장되지 않음 (QUERY_ALL_PACKAGES·VpnService 신고 필요)
