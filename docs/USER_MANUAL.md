# 이음 키즈 컬러링 사용자 매뉴얼

## 처음 화면

- **오늘의 추천 그림**: 매일 한 장씩 바뀝니다. 누르면 바로 색칠을 시작합니다.
- **이어서 색칠하기**: 칠하다 만 그림이 있으면 나타납니다.
- **동물 / 공룡 / 로봇과 우주 / 판타지 / 탈것 친구들**: 그림 30장이 다섯 묶음으로 나뉘어 있습니다. 옆으로 밀어서 고릅니다. 별(★) 개수는 난이도입니다.
- **내 그림**: 완성한 그림과 색칠하는 중인 그림을 모아 봅니다.
- **부모님**: 어른 확인(곱셈 문제)을 통과해야 들어갑니다.

## 색칠 화면

스마트폰(세로)은 아래쪽에 도구와 색이 있고, 태블릿·가로 화면은 왼쪽에 도구, 오른쪽에 색, 가운데에 그림이 있습니다.

### 위쪽 버튼
홈 · 저장 · 취소(실행 취소) · 다시(다시 실행) · 화면 맞춤 · 미리보기 · 다 했어요 · 더보기

### 도구
| 도구 | 쓰는 법 |
|---|---|
| 채우기 | 색을 고르고 그림 안쪽을 톡 누르면 그 칸이 채워집니다. 다른 색으로 다시 누르면 색이 바뀝니다. |
| 붓 / 색연필 / 크레용 / 형광펜 / 반짝이 | 손가락이나 펜으로 문질러 칠합니다. 굵기와 진하기를 조절할 수 있습니다. |
| 선 밖으로 안 나가기 | 켜 두면 처음 누른 칸 안에만 칠해집니다. |
| 지우개 | 문지른 곳을 지웁니다. 스티커를 누르면 스티커가 떼어집니다. |
| 칸 지우기 | 누른 칸에 칠한 것을 한 번에 지웁니다. |
| 스티커 | 별·하트·꽃·구름을 골라 그림 위를 누르면 붙습니다. 색은 고른 색으로, 크기는 '크기' 막대로 정합니다. |

### 화면 움직이기
- 두 손가락을 벌리거나 오므리면 확대·축소됩니다. 두 손가락으로 밀면 그림이 움직입니다.
- 채우기 도구에서는 한 손가락으로 밀어도 그림이 움직입니다.
- **화면 맞춤**을 누르면 처음 크기로 돌아옵니다.

### 색 고르기
- 기본(24색) · 더 많은 색 · 무지개 · 색각 친화 · 좋아하는 색 · 최근 색
- **＋ 나만의 색**: 색깔·선명하게·밝게 막대로 색을 만듭니다.
- 색을 **길게 누르면** '좋아하는 색'에 들어갑니다. (다시 길게 누르면 빠집니다.)

### 더보기
- **자동 색칠**: 색 묶음을 고르면 아직 안 칠한 칸을 자동으로 칠합니다. (바탕은 칠하지 않습니다.)
- **색칠 추천**: 어울리는 색 묶음을 색상판 맨 앞에 놓아 줍니다.
- **모두 지우기**
- **사진으로 내보내기**: 기기의 사진 폴더(Pictures/EumKidsColoring)에 PNG 로 저장합니다. Android 9 이하에서는 저장 위치를 고르는 화면이 나옵니다.
- **보내기**: 다른 앱으로 그림을 보냅니다. 항상 보호자 확인이 필요합니다.

### 저장
- 칠할 때마다 손을 떼고 2초 안에 자동으로 저장됩니다. 다른 앱으로 넘어가거나 화면을 끌 때도 바로 저장됩니다.
- 앱이 갑자기 꺼져도 '이어서 색칠하기'에서 그대로 다시 열 수 있습니다.
- **홈**이나 **뒤로 가기**를 누르면 "저장하고 나가기 / 지우고 나가기 / 계속 칠하기"를 고릅니다. 지우기는 한 번 더 확인합니다.
- **완성한 그림**을 열었다가 나갈 때는 묻지 않고 저장한 뒤 바로 나갑니다. 그림을 지우려면 **내 그림**에서 그림 이름 옆 **⋯ → 지우기**를 누릅니다.
- 실행 취소 기록은 저장되지 않습니다. (그림을 다시 열면 취소 버튼은 비어 있습니다.)

### 완성
바탕을 뺀 모든 칸을 채우기로 칠하거나 **다 했어요**를 누르면 축하 화면이 나오고 '완성한 그림'에 들어갑니다.

## 부모님 메뉴

- 나이에 맞는 그림(모두 / 3~5세 / 6~7세 / 8~10세): 30장을 난이도로 걸러 보여 줍니다.
- 효과음, 진동, 음성 안내, 애니메이션 줄이기, 색 이름 표시
- 펜으로만 그리기: 붓 도구에서 손가락은 화면 이동만 하고 펜으로만 그립니다.
- 보호자 확인 잠금: 사진 내보내기·그림 지우기 전에 어른 확인을 합니다.
- 개인정보처리방침, 도안 정보

## 펜(스타일러스)

- S Pen 등 스타일러스로 그릴 수 있고, 필압을 지원하는 기기에서는 세게 누르면 선이 굵어집니다.
- 펜을 쓰는 동안과 직후 0.6초 동안 손가락·손바닥 터치는 무시합니다.
- 펜의 지우개 쪽(지원 기기)으로 문지르면 지우개로 동작합니다.

## 알아 둘 점

- 인터넷 없이 모든 기능이 동작합니다.
- 음성 안내는 기기에 해당 언어의 음성(TTS)이 설치되어 있어야 소리가 납니다.

## 언어

기기 언어에 맞춰 자동으로 바뀝니다. 지원 언어: 한국어, 영어, 일본어, 스페인어, 포르투갈어, 중국어(간체·번체), 독일어, 프랑스어, 인도네시아어, 힌디어. 그 밖의 언어에서는 영어로 나옵니다.
