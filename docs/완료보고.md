## 1. 실제 구현한 기능

**1차 — 비대면계약·템플릿·내부결재·완료 PDF·감사 이력**
- 템플릿: 본문(`{{항목}}`), 입력 항목(작성자/참여자별, 필수·개인정보·공통 표시), 참여자 역할(외부·직원·직인), 수정 시 새 버전(이미 쓴 문서는 옛 버전 고정)
- 비대면: 개별 서명 링크(14일), 이메일·휴대폰 인증번호 선택, 끝까지 읽어야 동의 가능, 서명 거절(사유)
- 내부결재: 결재선 저장·재사용, 순차 결재, 승인·반려(사유 필수), 결재 대기·참조 알림, 타임라인, **승인 대상 버전·내용 해시 고정**, 결재 후 내용·서명 대상 변경 시 버전 올림 + 같은 결재선으로 새 차수 자동 상신(이전 승인 재사용 불가)
- 조건부 결재선: 계약금액·현장·문서 종류·거래처·방식·템플릿만 고르는 제한된 규칙(코드 실행 없음), 규칙에 걸린 문서는 결재 없이 발송 불가
- 완료 PDF: 한글 본문, 서명 이미지·시각·확인 방식, 사진대장(한 장 가로 2 × 세로 2), 도면, 첨부 PDF 원본 병합, 처리 이력 확인서(내용 해시·참여자·이력)
- 감사 이력: 회사별 해시 체인(중간 수정 시 검증 실패), 설정 › 감사 이력에서 체인 검증

**2차 — 대면·링크·대량**
- 대면: 담당자 화면/서명자 화면 분리, 지금 서명할 사람 크게 표시, 확인 방법 필수 기록(신분증 대조 등 + 확인 담당자 이름), 참여자별 1회용 30분 세션, 서명 후 세션 폐기·화면 지움, 다른 참여자 개인정보 `●●●●` 가림, **담당자 세션은 기기 넘기는 순간 서버에서 잠금 → 비밀번호로만 해제**, 로그인 직원은 서명자가 아니라 "확인 담당자"로 기록, 완료 후 수정 차단, 참여자별 완료 문서 전달 방법(메일·문자·안 함). 온라인 전용(오프라인 지원 표시 없음)
- 링크·QR: 템플릿·제목·안내문·접수 기간·건수 제한·인증(휴대폰/없음)·중복 정책·개인정보 동의 항목·제출 후 안내·내부 검토 단계, URL·QR PNG, 일시중지·종료·재개, 제출 현황, Excel·CSV 내보내기(CSV 수식 주입 방지). 접속만으로는 아무것도 생성·인정하지 않음
- 대량: 템플릿에서 전용 엑셀 양식 생성(수신자별 시트 + 공통값 시트 + 작성 안내), 필수 열·형식 검증, 행 번호별 오류, 중복 수신자·중복 요청 경고(파일 내 + 진행 중 문서), 오류 행 제외, 대표·개별 문서 미리보기, 작업 단위 결재, 발송 확인, 큐 발송, 성공·실패·서명 대기·완료 집계, 실패 건만 재시도, 완료 PDF ZIP, 진행 현황 Excel, 행별 계약 담당자 지정

**3차 — 조직 권한·자동분류·일정·메모**
- 업무 권한 16종(문서 작성·외부 발송·취소·부서/전체 열람·템플릿 작성/공유·직인 등록/사용/승인/폐기·일괄 발송·링크·조직·분류 규칙·API), 역할 기본값 + 개인별 지정
- 개인/회사 공용 서식, 부서·그룹·사용자 공유
- 직인: 등록·승인·사용·폐기 권한 분리, 모든 사용 기록, 사전날인은 승인된 서식·버전·사용자·금액 한도 안에서만(만든 사람 ≠ 승인자), "날인 사실"과 "대표자 승인"을 별도 열로 기록
- 퇴사: 로그인·세션·본인 API 키 차단, 문서·서식·대기 결재·서명 차례 인계, 기존 이력 유지
- 검색: 회사·부서·현장·거래처·종류·담당자·기간·금액·상태·태그·폴더·갱신 검토
- 자동분류: 폴더·태그 규칙(현장=A현장 → A현장 폴더, 근로계약서 → 인사, 금액 이상 → 중요계약, 종료 N일 이내 → 태그). 원본 하나, **권한 계산에 분류를 쓰지 않음**
- 일정: 서명 마감·시작·종료·갱신 검토(종료일−설정일수) 자동 생성, 담당자 수정 시 이후 자동값으로 덮지 않음 + 변경 이력, 며칠 전·대상(담당자/외부 참여자/직원)·채널·반복·처리 완료, **완료 계약도 알림**, 같은 알림 중복 없음
- 메모: 내부 메모 / 참여자 공유 의견, 답글·첨부·@언급·새 글 표시·알림·작성자·시각·수정/삭제 이력. 공개 범위는 서버에서 거름, 메모는 본문·상태에 영향 없음

**4차 — 브랜딩·클라우드·API·Webhook**
- 회사별 로고·색상·발신 이름·요청/완료 안내문·문의처, 서명·링크 화면 상단에 "서명을 요청한 회사" 표시
- 파일: 올린 순간 SHA-256 고정본으로 복사, 클라우드는 공급자별 모듈 자리(구글 드라이브·원드라이브·드롭박스) + 미연동 표시 + 로컬 업로드
- 외부 API, 회사별 키·범위·분당 제한·폐기·재발급, Idempotency-Key, 만료 다운로드 주소, Webhook HMAC 서명·타임스탬프·지수 백오프 재전송·전송 이력·수동 재전송, 수신 측 중복 처리 안내(docs/API_연동가이드.md)

**전기·통신공사 예시 흐름(새 계약 화면에 표시, 서식 5종 기본 제공 — 모두 "회사 검토용 예시", 기관 승인·법정 서식 표시 없음)**: A 근로계약 / B 자재 인수확인 / C 검측 확인(사진대장 2×2·도면) / D 협력업체 계약 / E 현장 동의서(QR)

## 3. 외부 연결이 있어야 실제로 동작하는 것
- **메일·문자 발송**: 지금은 발송함(설정 › 발송함)에 "미연결"로 기록만 됩니다. 발송 업체(SMTP, 문자 API) 어댑터를 붙여야 실제로 나갑니다. 인증번호도 같은 경로라, 연결 전에는 `DEV_SHOW_OTP=1`(개발용)로만 시험할 수 있습니다.
- **클라우드 파일**: 구글 드라이브·원드라이브·드롭박스는 연결 모듈 자리와 미연동 표시만 있고 실제 가져오기는 OAuth 앱 등록 후 구현해야 합니다.
- **본인확인기관(PASS·공동인증서 등)**, 공인 타임스탬프·PDF 장기검증 전자서명(PAdES)은 연결하지 않았습니다. 현재는 내용 해시 + 감사 해시 체인 + 인증 방식 기록입니다.
- 화면 글꼴 Pretendard 는 CDN 에서 받습니다(막히면 맑은 고딕 등으로 표시).

## 범용 계약 구조
- 업종 분류: 일반(B2B·B2C) / 부동산 / 건설 / 인사·노무. 새 계약·템플릿 화면이 분류별로 묶여 보입니다.
- 회사 당사자: 역할을 "회사"로 정하면 상호(필수)·사업자등록번호(형식 검사)를 받고, 서명란·확인서에 상호가 찍힙니다. 거래처를 따로 적지 않으면 상대 회사 상호가 거래처로 들어갑니다.
- 선택 참여자: 공동명의 임대인·임차인, 당사 중개사, 공동중개 중개사처럼 있을 때만 추가하는 참여자.
- 본문 시스템 값: {{@company}} 요청 회사, {{@date}} 계약일, {{@역할.name/org/orgno}}, {{금액|한글}} → "일금 삼억원정".
- 선택 목록 항목, 날짜 항목의 자동 일정 등록, 금액 합계 검증(계약금+중도금+잔금=총액), 기한 규칙(계약일·날짜 항목 ± 일수), 계약 전 확인 목록(체크 기록이 이력·완료 PDF에 남음).
- 예시 서식(일반): 용역(업무위탁), 물품 공급, 비밀유지(NDA), 서비스 이용(개인 고객, 필수·선택 동의 분리), 개인정보 수집·이용 동의서.

## 부동산
조사한 근거(공개 자료): 서울부동산정보광장 중개보수 요율표, 주택임대차보호법 제3조의7(임대인 정보 제시), 부동산 거래신고법 제3조(계약일부터 30일 신고), 전월세 신고제(보증금 6천만원 초과·월차임 30만원 초과, 30일, 확정일자 자동), 갱신 통지 기간(주택 6~2개월 전, 상가 6~1개월 전·10년), 공인중개사법 제25조(확인·설명서), 개인정보 보호법 제24조의2(주민등록번호 처리 제한).
- 예시 서식: 주택 임대차(전세·월세), 부동산 매매, 상가건물 임대차, 임대차 갱신·변경 합의서, 중개대상물 확인·설명서 수령 확인. 표준계약서 구성과 법령을 참고해 새로 쓴 회사 검토용이며 원문·법정 서식으로 표시하지 않습니다. 주민등록번호 대신 생년월일을 받습니다.
- 자동 일정: 중도금·잔금 지급일, 거래신고·임대차 신고 기한(완료일+30일), 갱신 통지 시작·마감.
- 부동산 도구 화면: 중개보수 상한 계산(주택 매매·임대차 구간별 요율·한도, 월세 환산 ×100/×70, 오피스텔·주택 외 0.9%), 계약 후 챙길 일 안내.

## 시험
15개 전부 통과 (기존 12 + 주택 임대차, B2B 용역, 중개보수 계산). 브라우저로 임대차 작성(합계 검증 표시·공동명의 추가)·확인 목록·도구·B2B 작성 화면 확인.

## 연결하지 않은 것
- 국토교통부 부동산 전자계약시스템·거래신고·임대차 신고·확정일자: 연결 없음. 일정과 안내만 제공하며 신고는 정부 시스템에서 따로 해야 합니다.
- 법정 서식인 중개대상물 확인·설명서 자체를 만들어 주지는 않습니다(원본 PDF를 첨부해 수령 확인을 받는 방식).
- 주택 중개보수 요율은 서울시 조례 기준입니다. 다른 시·도는 조례를 확인해야 합니다.
