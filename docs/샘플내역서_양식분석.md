# 샘플 원본 내역서 양식 분석 (파서 설계용)

분석일: 2026-10-24 / 대상 3개 파일

## 1. 양식 유형 요약

| 파일 | 양식 유형 | 핵심 시트 | 특징 |
|---|---|---|---|
| 강릉 통합공공임대주택 전기 내역서 | **적산프로그램 표준형 A** (원가/총괄표/내역서/일대목차/일위대가/합산자재/단가조사) | 원가, 총괄표, 내역서(1,173행), 일위대가(1,511행) | 공종줄·합계줄 마커, 공종 경로 `::` 구분, 수식 100% 유지, 숨김 `옵션` 시트가 원가 입력값 보관 |
| 칠곡 실내테니스장 소방 내역서 (.xlsm) | **표준형 A + 타 프로그램 양식 혼재** | 원가(발주부서 vs 착공 대비), 총괄표, 내역서, 일위대가 + `내역서 (2)`·`일위대가표`·`단가대비표`·`공량산출서`(기계소방 B형) | 매크로 파일, 외부 참조 `[1]옵션!`·`[2]합산자재!` 끊김, `#DIV/0!` 존재, 총괄표가 두 양식을 합산 |
| 동해안1 변환소 전력통신 설계서 (한전형) | **한전 설계서형 C** | 7.설계명세서, 집계표, 8-1~8-8 산출·일위대가·노임·단가비교 | 재료비/노무비 **시트 내 구역 분리**(단일 금액열), VLOOKUP 단가 연결, 공종 구분이 집계표 열(비금속광케이블/전원설비/LAN…)로 횡배치, `#REF!` 다수, 숨김 시트 30개 |

## 2. 양식 A (강릉·칠곡 내역서) 열 배치 — 가장 흔한 국내 적산 출력형

헤더 2행(2~3행), 데이터 5행부터.

| 열 | A | B | C | D | E | F | G | H | I | J | K | L | M | N | O | P | Q |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 의미 | 품목코드 | 공종코드/마커 | 코드 | 명칭 | 규격 | 단위 | 수량 | 재료비단가 | 재료비금액 | (노무)수량 | 노무단가 | 노무금액 | 경비단가 | 경비금액 | 합계단가 | 합계금액 | 비고(일위대가 번호 "제 34호") |

- 행 유형 판별: **B열 값**
  - `공종줄` → 공종 제목행, D열에 `대::중::소::세` 경로 (예 `1.전기공사::1-1.공동주택::1-1-1.전기단위세대공사::1-1-1-1.전기단위세대(52㎡-4세대)`)
  - `합계줄` → 공종 소계, I/L/N/P에 `TRUNC(SUM(...))`
  - 숫자 코드(`01010101`, `0101`) → 품목행
- 금액 수식: `I=TRUNC(G*H)`, `P=SUM(I,L,N)`, `O=IF((H+K+M)=0,"",H+K+M)`
- 단가 출처: `H=일대목차!I37`(일위대가 참조) 또는 `H=합산자재!H14`(자재단가 직접) → **단가 출처 2종을 수식에서 구분 가능**
- 원가 시트: C열 비목명, D(또는 E)열 금액, I(또는 L)열 요율, E/H열에 `(직접 노무비) * 15.1 %` 형식 기준 텍스트 → 제비율 자동 추출 가능
- 총괄표: 공종별 1식으로 `총괄표!I81` 식 내부 참조
- 일위대가: B열 `일목줄`(호 제목) / `제 N호`(구성품) / `합계줄`, 금액 `TRUNC(G*H,1)`(소수 1자리)
- 칠곡 원가 시트는 `발주부서(a) / 금액(b) / 증감액 / 절감율` 4열 대비형 — **당초·변경 대비표의 실제 선례**

## 3. 양식 B (칠곡 `내역서 (2)`, 기계소방)

헤더 3~4행, 데이터 6행부터. 품명 A, 규격 B, 단위 C, 수량 D, 재료비 단가/금액 E/F, 노무 G/H, 경비 I/J, 합계 K/L, 비고 M.
- 공종 제목행은 A열에만 `0101. 장비설치공사` (마커 없음 → 다른 열이 비어 있는 것으로 판별)
- 금액 `ROUNDDOWN(D*E,0)`, 단가 `=단가대비표!L41`, 수량 `=공량산출서!F8`
- N~AE열에 적용구분(기계경비/운반비/관급/사급자재대…) 보조열 — 원가계산 비목 분류 정보로 활용 가능

## 4. 양식 C (한전 설계서 `7.설계명세서`)

- 열: No./품명/규격/단위/수량/단가/금액/비고 (7열, 단일 금액). J~Q열에 동일 구조 복제본(변경 대비용 추정, `#REF!` 깨짐)
- 재료비/노무비가 **행 구역**으로 분리: `[ 재 료 비 ]` → `Ⅰ. 사 급 분` / `지입재료비` → `[ 노 무 비 ]`
- 공종(과목)은 `집계표`에서 열 단위(비금속광케이블·송변전광전송장치·전원설비·LAN,PIA·IP계통운영·무인보안)로 합산 — 구역 시작행 수식 `=SUM(G9:G28)` 범위로 공종 경계 역추적 가능
- 단가 `VLOOKUP(C9,'8-6.자재단가비교표'!$C$7:$O$332,12,0)`, 품명·수량은 `8-1.설비자재산출` 참조
- 일위대가(8-4)는 노무 품셈형: 직종/적용/할증1~3/노임단가 `VLOOKUP('8-5.2025하노임')`, `INT(G*H*I*J*K)`
- 간접비: `INT(F9*$D$10)`, 공구손료 `INT((F9-제외금액)*3%)` — 비목별 제외액 하드코딩 존재

## 5. 파서가 반드시 처리해야 할 실제 이슈 (샘플에서 확인됨)

1. 외부 링크 끊김: `=[1]옵션!$D$2`, `=[2]합산자재!H98` → 캐시값만 사용, "외부참조" 경고
2. `#REF!`, `#DIV/0!` 오류 셀 → 검증 목록에 수집, 금액 0으로 대체 금지
3. 숨김 시트(`옵션`, `합산자재`, 한전형 30개) → 숨김이어도 참조 대상이면 로드
4. 매크로(.xlsm) → openpyxl `keep_vba=True`로 원본 보존, 출력본은 .xlsx 별도 생성
5. 금액 반올림 규칙이 양식별로 다름: `TRUNC(…,0)` / `TRUNC(…,1)` / `ROUNDDOWN` / `INT` → 수식에서 자동 감지해 현장 설정 기본값으로 제안
6. 공종 깊이 4단계(`::` 4개)까지 실제 존재 → 트리 depth 무제한
7. 동일 품명+규격이 여러 공종에 반복(전기단위세대 4타입) → `공종경로 + 코드 + 행번호` 조합 ID
8. 수량이 수식(`=산출집계!H7`)인 경우와 숫자인 경우 혼재 → 계약수량은 **캐시값(data_only)** 기준, 수식은 출처 메타로 보관
9. 총괄표 "1식" 행은 하위 공종 금액의 합 → 기성에서는 수량 입력 대상이 아니라 자동 집계 행으로 처리
10. 1행 `총줄수->` 등 프로그램 제어 셀, W~AE 보조열(노임계·부속재) → 출력 시 숨김/제외 옵션

## 6. 시트 역할 자동 분류 사전 (초기값)

| 역할 | 시트명 패턴 |
|---|---|
| 원가계산서 | 원가, 원가계산서, 공사비예산서, 공사비총괄표, 집계표 |
| 총괄내역 | 총괄표, 총괄내역서, 집계표 |
| 공종별내역 | 내역서, 내역서 (n), 설계명세서, 산출내역 |
| 일위대가 | 일위대가, 일위대가표, 일대목차, 일위대가목록, 일위노임 |
| 자재단가 | 합산자재, 단가조사, 단가대비표, 자재단가비교표 |
| 수량산출 | 산출집계, 기본산출서, 공량산출서, 수량산출서, 설비자재산출, 노무산출 |
| 노임 | 노임근거, 일위노임, 2025하노임 |
| 참조/기타 | 옵션, 공종리스트, 사용설명, 표지, 목차, 시방서, 도면 |

이름이 사전에 없으면 헤더 키워드(`품명/규격/단위/수량/단가/금액`, `재료비/노무비/경비`, `당초/변경/증감`)와 B열 마커(`공종줄/합계줄/일목줄`)로 2차 판별.

## 7. 설계변경 샘플 (평창 에코랜드 전기 1회 변경 설계서) — 변경내역서 출력 양식 선례

시트 구성: 증감총괄 / 표지 / 결재란 / 목차 / 1.설계변경사유서 / 갑지 / 7-1.증감내역 / 원가계산 / 공종별집계표 / 증감대비표 / 변경내역서 / 신규_공종별내역서 / 신규_일위대가목록 / 신규_일위대가 / 신규_단가대비표 / 신규_공량산출근거서 / 일위대가·일위노임·합산자재·단가조사·옵션(원본 유지)

| 시트 | 구조 | 프로그램 매핑 |
|---|---|---|
| **변경내역서** | 양식 A와 동일 열 + **품목당 2행(당초행/변경행)**. 당초행에 `P=G6-G5`(증감수량), `Q=O6-O5`(증감금액). 변경행은 수량·단가·금액만, 명칭은 당초행에만 | "설계변경 공종별 내역서(당초/변경 2행형)" 출력 템플릿 |
| **증감대비표** | 명칭/규격/단위/수량 + 당초(단가·수량·금액) / 변경(단가·수량·금액) / 증감(단가·수량·금액). 첫 행 B열에 공종 경로 `1.옥외공사::1-1.옥외보안등공사`, 값은 `=변경내역서!N5` 참조 | "설계변경 대비표" 표준 출력 |
| **공종별집계표** | 공종당 2행(당초/변경) 1식, `Q=P6-P5` 증감 | "설계변경 총괄표" |
| **원가계산** | 비목 / 변경전 원가(E) / 변경후 원가(F) / 증감(G) / 구성비(H~J: `직접노무비 × 0.131`) / 비고. 보험료 항목(건강·연금·노인장기요양·퇴직공제)은 **상수 고정** ("보험료정산" 비고) | "변경 원가계산서"; 정산 비목은 변경 시 재계산 제외 옵션 필요 |
| **7-1.증감내역** | 비목별 당초/변경/증(▲)감 | "증감금액 집계표" |
| **증감총괄** | 총공사비·도급액·관급·한전불입금 당초/변경/증/△감, "천단위절사" | "설계변경 총괄표" 상단 |
| **1.설계변경사유서** | 변경 사유 + 세부내역/제외내역 공종 목록 | 변경차수 메타(사유) 출력 |
| **신규_*** | 신규 품목은 별도 프로그램 양식(품명 A, 규격 B…, `TRUNC(E*D,0)`), `신규호표 N` 비고, 신규 일위대가는 `TRUNC(…,1)` + 부속품비 15%/잡재료비 2%/공구손료 3% 식 | 신규 품목 내역서·신규 일위대가표 출력 |

핵심: 국내 관행은 **당초/변경을 같은 표 안에 2행으로 쌓는 방식**과 **좌우 3블록(당초·변경·증감) 방식** 두 가지가 공존 → 두 템플릿 모두 제공.
