파일관리자2 — PC 연결 기능의 포그라운드 서비스(dataSync) 시연

사용자가 'PC 연결'에서 로그인하고 연결을 켜면 상시 알림과 함께 포그라운드 서비스가 시작됩니다. 사용자가 승인한 PC가 휴대폰의 허용된 폴더 목록을 보고 파일을 주고받는 네트워크 작업을, 앱을 닫은 뒤에도(홈 화면) 알림이 표시된 상태로 처리합니다. 사용자는 알림의 '연결 끄기' 또는 앱의 스위치로 언제든 중지할 수 있습니다.

This video shows the user turning on "PC Connect"; a foreground service (type dataSync) with an ongoing notification keeps a network connection so an approved PC can list and transfer files in user-approved folders while the app is in the background. The user can stop it anytime from the notification or the in-app switch.
