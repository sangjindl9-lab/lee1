# 사용자 매뉴얼

## 1. 처음 한 번
1. 로그인 → **API 연결 관리**에서 키 등록 → "저장하고 연결 확인". "키 등록됨"과 "연결 확인됨"은 다르게 표시됩니다.
2. 같은 화면 아래 **모델 목록·단가**에서 단가를 확인합니다. 단가가 비어 있는 모델은 비용을 계산할 수 없어, 승인 없이는 쓰이지 않습니다.
3. **환경설정**에서 영상 1개 최대 비용, 일·월 비용 한도, 일일 제작 수량을 정합니다.

## 2. 만들기
메인 화면에 주제를 한 줄 쓰고 **제작 시작**. 나머지는 모두 AI 자동이 기본값입니다.
고급 설정: 제작 모드(풀오토·경제형·고품질형·시네마틱형), 길이(15~180초), 언어, 최대 비용, 출력 규격, 스타일, 고정 캐릭터, 음성, 모델.

| 모드 | 화면 구성 |
|---|---|
| 경제형 | 전 장면 이미지 + 자체 줌·팬 애니메이션 |
| 고품질형 / 풀오토 | 오프닝과 움직임이 중요한 장면만 영상 모델, 예산의 85%를 넘으면 중요도 낮은 장면부터 이미지로 전환 |
| 시네마틱형 | 전 장면 영상 모델 (비용 최대) |

## 3. 진행 화면
17개 단계가 눈금으로 표시되고, 실시간 기록·사용 비용·예상 최대 비용이 보입니다. 창을 닫아도 서버에서 계속 진행합니다.

- **승인 대기**: 예상 비용이 한도를 넘거나 단가 미등록 모델이 있을 때. 이 시점까지 해당 단계의 유료 호출은 실행되지 않았습니다. 한도를 올리거나 허용 후 "승인하고 계속".
- **실패**: 원인이 표시됩니다(예: API 잔액 부족). 조치 후 "실패한 단계부터 다시" — 이미 만든 대본·이미지·음성은 재사용됩니다.
- **중지**: 다음 확인 지점에서 멈추고, 대기열에 있던 Higgsfield 요청은 취소를 시도합니다.

## 4. 결과
- **MP4 받기**, **업로드 패키지(zip)**: 영상, SRT·VTT 자막, 커버 프레임, 제목 5개·설명·해시태그·고정 댓글·출처·정책 검사 결과·비용.
- 탭: 장면(프롬프트·모델·음성), 대본·출처(사실별 URL·발표일·확인일·신뢰도), 기획·조사(기획안 3개와 선정 이유, 참고 영상 지표), 품질검수(100점 배점과 지적 사항), 비용, 기록.
- 품질 점수는 내부 지표이며 유튜브 알고리즘·조회수를 보장하지 않습니다. 정책 검사도 사전 점검일 뿐 수익 창출이나 저작권 문제 없음을 보장하지 않습니다.

## 5. 편집기
장면의 문장·프롬프트·화면 종류·전환·자막 위치, 자막 디자인을 고친 뒤 "다시 만들기". 문장을 바꾸면 그 장면의 음성만, 프롬프트를 바꾸면 그 장면의 이미지만 새로 만듭니다.

## 6. 업로드
**유튜브 채널 연결**에서 본인 채널을 연결 → 결과 화면의 업로드 영역에서 채널·공개 범위를 고르고 **승인 체크** 후 업로드. 기본은 비공개이며 승인 없는 자동 업로드는 없습니다.
업로드한 영상은 24시간·3일·7일 시점의 본인 채널 지표를 자동 수집하고, 다음 제작의 기획 단계에 참고 자료로 전달합니다.

## 7. 그 밖의 메뉴
- **인기 주제 찾기**: 지역 인기 차트를 근거로 새 주제 제안 → 바로 만들기.
- **유튜브 콘텐츠 분석**: 검색어의 인기 쇼츠 후보와 공개 지표(시간당 평균 조회수, 구독자 대비, 좋아요율, 길이 분포, 상위 댓글).
- **예약 제작**: 여러 주제를 등록하면 한 번에 하나씩 순서대로 제작. 거의 같은 주제는 자동 제외.
- **캐릭터 관리**: 얼굴·의상 등을 고정. Higgsfield Soul ID가 있으면 참조로 전달.
- **채널 브랜딩**: 로고(좌측 상단), 브랜드 색, 기본 자막 스타일.
- **음악 라이브러리**: 이용 허락 정보와 함께 등록. "상업적 이용 가능"으로 확인한 곡만 자동 선정되며, 없으면 배경음악 없이 제작합니다.
- **음성 라이브러리**: 기본 음성 지정. 발음 사전은 환경설정에 있습니다.
