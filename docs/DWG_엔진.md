# DWG 변환 엔진 설정·지원 범위

DWG는 공개 규격이 아니므로 프로그램이 직접 읽지 않고 **외부 변환 엔진으로 DXF로 바꾼 뒤** DXF 해석기를 사용합니다. 엔진이 없으면 DWG 업로드는 "설정 필요" 오류와 함께 DXF·PDF 업로드를 안내합니다.

## 지원 엔진
| 엔진 | 라이선스 | 설정 값 | 비고 |
|---|---|---|---|
| LibreDWG 0.13.3 `dwg2dxf` | GPLv3 이상 (외부 실행 프로그램으로 호출) | 종류 `libredwg`, 경로 `/opt/libredwg/bin/dwg2dxf` | Dockerfile에서 소스 빌드. 검증 환경에서 실제 변환 확인 |
| ODA File Converter | ODA 이용 약관 동의 후 무료 배포 (상용 사용·재배포 조건은 ODA 약관 확인 필요) | 종류 `oda`, 경로 `ODAFileConverter` 실행 파일 | 실행 인자: `입력폴더 출력폴더 ACAD2018 DXF 0 1 파일명`. 이 환경에서는 설치·실행 검증하지 않음 |

설정 방법: 관리자 → DWG 변환 엔진 → 경로 입력 → "연결 시험" → 저장. 또는 환경변수 `DWG_ENGINE_TYPE`, `DWG_ENGINE_PATH`.

## 지원 버전 (LibreDWG 기준)
- 읽기: R13~R2018 계열(AC1012~AC1032) 대부분. R2004 이후 일부 객체는 변환 품질이 떨어질 수 있습니다.
- 검증: LibreDWG 공식 시험자료의 AutoCAD 저장 DWG 6종(R2000·R2004·R2007·R2010·R2013·R2018, `samples/input/dwg_real`)을 모두 변환·판독했습니다(객체 218개, 단위 mm, 미지원 경고 0건).
- DWG 쓰기(DXF→DWG): LibreDWG `dwgwrite`는 검증에서 블록 테이블 누락·객체 손실이 확인되어 **사용하지 않습니다.** DWG 내보내기는 ODA File Converter 연결 시에만 활성화됩니다.

## 제한 사항
- 해치 채움, 이미지(IMAGE), 3D 객체, OLE, 동적 블록 매개변수, 테이블, 다중 지시선 등은 표시하지 않거나 근사 표시하며 업로드 결과에 "미지원/근사 객체 N개"로 알립니다.
- SPLINE: 제어점·매듭이 있으면 B-스플라인(de Boor)으로 계산, 맞춤점만 있으면 맞춤점을 지나는 보간 곡선으로 표시합니다.
- ATTDEF(블록 속성 정의)는 AutoCAD와 같이 표시하지 않고 ATTRIB 값을 표시합니다.
- 외부참조(XREF)는 포함되지 않습니다. 업로드 결과에 누락된 참조 목록을 표시하며, CAD에서 바인드 후 다시 업로드해야 합니다.
- SHX 등 CAD 글꼴은 서버에 없으므로 Noto Sans KR로 대체 표시합니다(글자 폭·위치 차이 가능).
- 인코딩: UTF-8 우선, 깨짐 감지 시 EUC-KR(CP949)로 재해석합니다.
- DWG 내보내기는 ODA File Converter 경로(관리자 > DWG 변환 엔진 > DWG 내보내기용 ODA 경로)가 설정된 경우에만 활성화됩니다.
