## 2. 코드는 있으나 실제 호출로 검증하지 못한 것 (키·계정·예산 필요)

- **모든 외부 유료 API의 실호출**: Higgsfield, Claude, ElevenLabs, Tavily, YouTube Data API. 공식 문서 규격대로 작성했고 모의 응답으로만 확인했습니다.
- OpenAI(LLM·TTS·Whisper·이미지), Gemini, Brave 어댑터: 모의 테스트도 없음.
- YouTube OAuth 연결, `videos.insert` 업로드, YouTube Analytics 수집: 실계정 미확인.
- S3/R2 저장소 어댑터.
- Docker 이미지 빌드, docker compose, GitHub Actions, Railway·Render 배포: 이 환경에 Docker 데몬이 없어 실행하지 못함. `render.yaml` 문법도 미확인.
- 60fps, 2160×3840 출력(코드 경로는 같으나 30fps·1080p만 실측). 4K는 확대 출력이며 네이티브 4K로 표시하지 않습니다.
- 기본 등록 모델 ID(`claude-sonnet-5-5` 등)와 단가: 연결 테스트의 모델 목록·콘솔 가격으로 확인 필요. Higgsfield 이미지 모델 단가는 공식 가격 페이지에서 찾지 못해 비워 두었습니다.
- **승인된 테스트 예산으로 만든 실제 쇼츠 영상(산출물 18)**: 아직 없음.
