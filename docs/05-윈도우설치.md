# WebNVR 윈도우 설치판 — 설치·운영 안내 (v0.4.0)

WebNVR 윈도우 설치판은 두 가지로 쓸 수 있습니다.
- **녹화 서버 + 관제 프로그램**: 카메라를 녹화할 PC에 설치합니다. 윈도우 서비스로 등록되므로 로그인하지 않아도, 화면을 꺼도 녹화가 계속됩니다.
- **관제 프로그램만**: 관제원 PC에 설치하고, 서버에 접속해 관제 화면과 영상벽(여러 모니터)을 띄웁니다.

리눅스 Docker 설치판과 기능이 같습니다. 웹 브라우저로도 접속할 수 있습니다.

## 1. 준비물
| 항목 | 권장 |
|---|---|
| 운영체제 | 윈도우 10/11 64비트 또는 Windows Server 2019/2022. **Pro 이상 권장**: 윈도우 업데이트 재부팅 시간을 관리할 수 있어야 합니다 |
| CPU·메모리 | 카메라 16대 이하: 4코어, 8GB. 지능형 분석을 쓰면 사람 분석 카메라 1대당 0.5코어를 더합니다 |
| 녹화 디스크 | 윈도우가 설치된 C: 가 아닌 **전용 디스크(D: 등)**. 감시용(Surveillance) HDD 를 권장합니다 |
| 네트워크 | 카메라와 같은 LAN, 고정 IP |
| 관제 PC | 윈도우 10/11 + Microsoft Edge WebView2 런타임(윈도우 11 은 기본 포함) |

## 2. 설치
1. `WebNVR-Setup-0.4.0.exe` 를 관리자 계정으로 실행합니다.
2. 구성 요소를 고릅니다. 서버 PC 는 ‘녹화 서버 + 관제 프로그램’, 관제원 PC 는 ‘관제 프로그램만’을 고릅니다.
3. 서버를 고르면 설정 화면이 나옵니다.
   - **녹화 저장 폴더**: D: 드라이브가 있으면 `D:\WebNVR\recordings` 가 기본값입니다.
   - **접속 주소**: 비우면 이 PC 의 IP 를 자동으로 씁니다. 도메인을 쓰려면 여기에 입력합니다.
   - **최고관리자 ID·비밀번호**: 10자 이상이고, 영문 대문자·소문자·숫자·특수문자 중 3종류 이상을 섞어야 합니다.
4. 설치 프로그램이 다음 작업을 자동으로 합니다(수 분 걸릴 수 있음).
   - DB 를 초기화합니다(PostgreSQL 16, 이 PC 안에서만 접속, 포트 54329).
   - 윈도우 서비스 7개를 등록합니다.
   - 방화벽을 엽니다: TCP 443·80, UDP 8189. ‘도메인·개인’ 네트워크에만 엽니다.
   - 웹 접속 인증서를 만들어 이 PC 의 신뢰 목록에 넣습니다.
   - 443 이나 80 포트를 IIS 같은 다른 프로그램이 이미 쓰고 있으면 8443 이나 8080 으로 바꿔 설정합니다.
5. 설치가 끝나면 **관제 프로그램**을 실행해 로그인합니다. 첫 로그인 때 비밀번호를 한 번 더 바꿔야 합니다.
6. 작업표시줄 알림 영역에 **서버 관리** 아이콘이 생깁니다. 초록색은 정상, 빨간색은 일부 서비스가 멈춘 상태입니다.

> 설치 중 입력한 관리자 비밀번호는 DB 에 암호화된 형태(argon2)로만 저장됩니다. 설치 프로그램이 넘긴 임시 파일은 바로 지웁니다.

## 3. 관제 프로그램
- **서버 목록**: 처음 실행하면 서버 목록 화면이 나옵니다. 서버 PC 에서는 ‘이 컴퓨터(서버)’가 자동으로 들어 있습니다. 다른 서버는 주소(예: `192.168.0.10`)로 추가합니다.
- **처음 접속하는 서버**: 서버 인증서가 사설 인증서라 **지문(SHA-256)** 을 보여 줍니다.
  1. 서버 PC 의 ‘서버 관리 아이콘 → 인증서 지문 보기’와 같은지 확인합니다.
  2. 같으면 ‘이 서버 신뢰’를 누릅니다.
  3. 윈도우 보안 경고 창에서 ‘예’를 누르면 현재 사용자의 신뢰 목록에 들어가고, 다음부터는 묻지 않습니다.
- **영상벽(여러 모니터)**:
  1. 관제 화면의 ‘실시간 관제’에서 원하는 분할과 카메라를 배치한 뒤 **새 배치로 저장**합니다(예: `모니터2`).
  2. 서버 선택 화면의 ‘영상벽 모니터’에서 모니터 2·3…에 배치 이름과 순환 간격을 적고 저장합니다.
  3. 접속하면 각 모니터에 전체화면으로 열립니다. 메뉴 ‘영상벽 → 열기·닫기’로도 조절할 수 있습니다.
  4. 모든 창이 같은 로그인을 씁니다.
- **메뉴**: 서버 → 서버 선택 화면, 보기 → 전체화면, 새로 고침.
- 내보내기 MP4 와 스냅샷을 받을 때는 저장 위치를 묻는 창이 뜹니다.

## 4. 서버 관리
**서버 관리 아이콘(오른쪽 클릭)**
- 서비스 상태를 봅니다.
- ‘서비스 다시 시작’과 ‘지금 백업’을 할 수 있습니다. 둘 다 관리자 확인이 필요합니다.
- 인증서 지문을 보고, 녹화 폴더와 로그 폴더를 열 수 있습니다.

**관리 명령**: 시작 메뉴 → ‘WebNVR 관리 명령(nvrctl)’을 **관리자 권한으로** 실행합니다.
```
nvrctl status                 서비스 상태·남은 공간
nvrctl restart [recorder]     전체 또는 일부 다시 시작
nvrctl config                 설정 보기
nvrctl config NVR_ANALYTICS_DETECT_INTERVAL=2   설정 바꾸기 → nvrctl upgrade 로 반영
nvrctl backup D:\backup       DB·마스터 키·설정·인증서 백업(zip)
nvrctl restore D:\backup\webnvr-backup-….zip
```

**서비스**(윈도우 ‘서비스’ 관리 도구에도 보입니다)

| 서비스 | 역할 |
|---|---|
| WebNVR-DB | PostgreSQL |
| WebNVR-API | 관리 API |
| WebNVR-Media | 실시간 중계 |
| WebNVR-Recorder | 녹화 |
| WebNVR-Worker | 보관 정리·내보내기·알림 |
| WebNVR-Analytics | 지능형 분석 |
| WebNVR-Proxy | HTTPS 웹 접속 |

- 모두 **NetworkService** 계정(관리자 권한 없음)으로 돌고, 멈추면 자동으로 다시 시작합니다.
- 서비스 로그는 `%ProgramData%\WebNVR\logs` 에 있습니다.

**폴더**

| 폴더 | 내용 |
|---|---|
| `C:\Program Files\WebNVR` | 프로그램 |
| `%ProgramData%\WebNVR` | 설정(nvr.env)·DB·비밀 파일·로그 |
| 녹화 폴더 | 영상 |

비밀 파일 폴더(secrets)는 SYSTEM·Administrators 만 쓸 수 있고, 서비스 계정은 읽기만 합니다.

## 5. 업데이트·제거
- **업데이트**: 새 설치 프로그램을 실행하면 됩니다. 서비스를 멈추고 파일을 바꾼 뒤 DB 구조를 갱신하고 다시 시작합니다. 설정과 녹화는 그대로 남습니다. 업데이트 중에는 녹화가 몇십 초 끊깁니다.
- **제거**: ‘설정 → 앱’ 또는 시작 메뉴의 ‘WebNVR 제거’를 씁니다. 설정·DB 를 지울지 묻습니다. **녹화 영상 폴더는 어느 경우에도 지우지 않습니다.**

## 6. 운영 주의
- **윈도우 업데이트**: ‘사용 시간’을 24시간으로 두거나, 그룹 정책으로 자동 재부팅 시각을 정하세요. 재부팅되면 서비스는 자동으로 다시 뜨지만, 재부팅하는 동안(수 분)은 녹화가 끊깁니다.
- **절전**: 제어판 → 전원 옵션에서 ‘절전 모드 안 함’, 하드 디스크 끄기 ‘사용 안 함’으로 두세요.
- **백신 실시간 검사**: 녹화 폴더와 `%ProgramData%\WebNVR\pgdata` 를 검사 제외로 두면 디스크 부하와 파일 잠김이 줄어듭니다.
- **원격 관제**: 관제 PC 가 다른 망에 있으면 VPN 으로 접속하세요. 공유기 포트포워딩으로 인터넷에 직접 여는 것은 권하지 않습니다.
- **같은 PC 의 다른 NVR·VMS 프로그램**: 포트(443·80·8189·54329·18000·8888·8889)가 겹치면 설치할 때 바꾸거나 `nvrctl config` 로 바꾸세요.

## 7. 문제 해결
| 증상 | 확인 |
|---|---|
| 관제 프로그램이 열리지 않음 | WebView2 런타임 설치 여부. 시작 메뉴에서 ‘WebNVR 관제’ 다시 실행 |
| ‘서버에 연결하지 못했습니다’ | 서버 PC 전원·IP, 방화벽(443), `nvrctl status` |
| 인증서 지문이 다름 | 다른 장비가 그 주소를 쓰고 있거나 서버를 다시 설치함 — 서버 관리 아이콘의 지문과 대조 후 판단 |
| 서비스가 계속 다시 시작됨 | `%ProgramData%\WebNVR\logs\WebNVR-<이름>.err.log` |
| 녹화 폴더 쓰기 오류 | 폴더 권한: `icacls <녹화폴더> /grant *S-1-5-20:(OI)(CI)M` |
| 443 포트 충돌 | `nvrctl config NVR_HTTPS_PORT=8443` → `nvrctl upgrade` |

## 8. 검증 상태
- 이 설치판은 리눅스에서 교차 패키징했습니다. **윈도우 PC 에서 설치·실행해 본 시험은 아직 없습니다.** 자세한 내용은 docs/03-검증결과.md 의 ‘윈도우 설치판’ 항목을 보세요.
- 처음 설치할 때는 시험용 PC 에서 다음을 확인한 뒤 현장에 쓰세요.
  - 설치
  - 카메라 1대 녹화
  - PC 재부팅 후 자동 재시작
  - 관제 프로그램 접속
  - 업데이트 설치
  - 제거
