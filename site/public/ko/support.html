도움말·문의

주문 화면을 어떻게 저장하나요?

쇼핑 앱에서 주문 내역을 열고 ‘공유’를 누른 뒤 ‘이음 구매노트’를 고르세요. 캡처한 화면은 갤러리에서 열고 공유하면 됩니다. 홈의 ‘구매 추가’로 직접 입력할 수도 있습니다.

글자를 잘못 읽었어요

앱은 읽은 값을 자동으로 넣지 않습니다. 후보 중 맞는 값을 누르거나 직접 고쳐 주세요. ‘글자 언어’를 바꿔 다시 읽을 수도 있습니다.

기한은 자동으로 정해지나요?

아니요. 영수증에 적혀 있고 사용자가 확인한 날짜나 직접 입력한 날짜만 저장합니다. ‘수령 후 7일’처럼 기준일이 분명하지 않으면 비워 두고 안내합니다.

알림이 늦게 오거나 안 와요

휴대폰 절전 설정에 따라 늦을 수 있습니다. 알림 권한이 꺼져 있으면 설정에서 켜 주세요. 기한은 앱 홈에서 항상 볼 수 있습니다.

휴대폰을 바꾸면요?

설정 > 백업·복원에서 암호 백업 파일을 만들어 새 휴대폰으로 옮긴 뒤 복원하세요. 암호를 잊으면 복원할 수 없습니다.

데이터를 지우고 싶어요

설정 > ‘모든 데이터 삭제’를 누르세요. 갤러리의 원본 사진은 지워지지 않습니다.
