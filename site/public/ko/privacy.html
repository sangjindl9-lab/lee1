이음 구매노트 개인정보 처리방침

요약

이음 구매노트(이하 ‘앱’)는 개인정보를 수집하거나 외부로 보내지 않습니다. 가입·로그인·광고·추적·외부 분석 도구가 없습니다.

구매 기록과 사진은 휴대폰 밖으로 보내지 않습니다. 인터넷은 아래 ‘쇼핑몰 화면 가져오기’에만 사용합니다.

쇼핑몰 화면 가져오기

사용자가 고른 쇼핑몰(예: 쿠팡, 네이버, 아마존) 공식 사이트를 앱 안 브라우저로 엽니다. 로그인은 사용자가 그 사이트에 직접 하며, 앱은 아이디·비밀번호를 읽거나 저장하지 않습니다.

사용자가 ‘이 화면 가져오기’를 누를 때만 지금 보이는 주문 내역 화면의 글자를 휴대폰 안에서 읽어 구매 기록으로 만듭니다. 이 내용은 운영자 서버로 보내지 않습니다.

쇼핑몰 사이트와의 통신과 로그인 상태(쿠키)는 해당 쇼핑몰의 개인정보 처리방침을 따릅니다. 설정 > ‘쇼핑몰 로그인 정보 지우기’로 언제든 지울 수 있습니다.

가져오기 규칙(쇼핑몰 화면을 읽는 방법)은 이 안내 서버에서 내려받습니다. 이때 개인정보는 보내지 않습니다.

앱이 휴대폰 안에 저장하는 정보

사용자가 입력하거나 고른 구매 정보: 상품명, 구매처, 주문일, 금액·통화, 주문번호, 구매처 링크, 메모, 반품·교환·AS 기한, 상태, 알림 설정.

사용자가 공유하거나 직접 고른 사진의 사본과, 그 사진에서 휴대폰 안에서 읽은 글자.

이 정보는 앱 전용 저장 공간에만 있으며 운영자는 볼 수 없습니다. 안드로이드 자동 클라우드 백업·기기 간 이전 대상에서도 제외했습니다.

사진과 글자 인식

앱은 사용자가 공유하거나 시스템 사진 선택 화면에서 고른 파일만 읽습니다. 사진·저장소 전체 접근 권한을 요청하지 않으며, 갤러리의 원본 사진을 지우거나 바꾸지 않습니다.

글자 인식은 앱에 포함된 Google ML Kit 기기 내 모델로 휴대폰 안에서 처리하며, 사진이나 인식 결과를 외부로 보내지 않습니다. ML Kit의 사용 통계 전송 기능은 앱에서 제거했습니다.

권한

인터넷: 쇼핑몰 화면 가져오기와 가져오기 규칙 받기에만 사용합니다.

알림(선택): 사용자가 정한 기한 알림을 보내기 위해 사용합니다. 거부해도 앱 안에서 기한을 볼 수 있습니다. 잠금 화면에는 상품명·주문번호가 보이지 않는 알림만 표시됩니다.

부팅 완료 수신: 휴대폰을 다시 켠 뒤 알림을 다시 예약하기 위해 사용합니다.

백업

사용자가 요청할 때만, 사용자가 고른 위치에 암호를 건 백업 파일(AES-256)을 만듭니다. 그 위치가 클라우드 서비스라면 해당 서비스의 정책이 적용됩니다. 암호를 잊으면 운영자도 복원할 수 없습니다.

보관과 삭제

정보는 사용자가 지우거나 앱을 삭제할 때까지 휴대폰에 남습니다. 설정 > ‘모든 데이터 삭제’로 언제든 지울 수 있습니다.

백업 파일 없이 앱을 삭제하면 기록을 되살릴 수 없습니다.

제3자 제공

운영자는 정보를 받지 않으므로 제3자에게 제공하거나 판매하지 않습니다.

아동

이 앱은 연령을 묻지 않으며, 어린이를 주 대상으로 만든 앱이 아닙니다. 어떤 연령의 사용자 정보도 수집하지 않습니다.

이 안내 페이지

이 웹페이지를 제공하는 서버(Railway)는 일반적인 접속 기록(IP 주소, 시각, 요청 주소)을 운영 목적으로 일정 기간 남길 수 있습니다. 이 페이지는 쿠키나 분석 도구를 쓰지 않습니다.
