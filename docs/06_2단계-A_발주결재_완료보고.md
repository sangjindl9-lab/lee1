# 2단계-A 완료 보고 — 자재·발주서·대표이사 결재·납품검수

| 항목 | 내용 |
|---|---|
| 범위 | 2단계 중 구매 흐름: 자재마스터 → 발주서 작성 → **대표이사 결재** → 발주서 PDF → 납품·검수(부분납품) |
| 회사 규정 반영 | **모든 발주서는 대표이사 결재.** 결재선 설정에서 대표이사 앞에 검토 단계를 더할 수는 있지만, 마지막 결재가 대표이사가 아닌 결재선은 저장되지 않습니다 (서버에서 거부). |
| 검증 | 실제 PostgreSQL 대상 자동 테스트 **72 / 72 통과** (1단계 50 + 2단계 22), 브라우저 조작 시나리오(구매담당 작성 → 대표이사 승인 → 현장 검수), 발주서 PDF 실물 확인 |

---

## 1. 완료된 기능

| 영역 | 기능 |
|---|---|
| 자재마스터 | 등록·수정·삭제·검색·분류·공종, 과세/면세/영세, 기본 매입단가, **엑셀 대량 등록**(양식 내려받기 → 행별 검사 미리보기 → 오류가 하나라도 있으면 저장 안 함), 엑셀 출력, **거래처별 최근 매입단가 자동 누적**(대표이사 승인 시점) |
| 발주서 작성 | 현장·거래처 검색 선택, 엑셀처럼 입력하는 품목표(방향키·Enter 이동, 마지막 행 Enter 시 새 행), **품명 칸에서 자재마스터 검색**(이 거래처의 최근 단가 우선), **엑셀에서 여러 행 복사·붙여넣기**, 품목별 공급가액(원 미만 절사)·과세 품목만 부가세, 합계 실시간 미리보기 — 확정 금액은 서버가 다시 계산, 결재선 미리보기, 임시저장(Ctrl+S) |
| 전자결재 | 상신 → 결재함 → 승인·반려(사유 필수)·보류, 기안자 회수(아무도 처리 안 했을 때만), 반려 후 수정·재상신(이전 결재 이력 보존), 금액 구간별 결재선, **결재 차례인 역할만 처리 가능**(최고관리자도 대표이사 결재를 대신할 수 없음), 동시 승인 방지(행 잠금 + 버전), 결재 기록 삭제·처리된 단계 변경을 DB 트리거로 차단, 사이드바·모바일 하단 탭에 결재 대기 배지 |
| 발주서 문서 | 화면에서 종이 양식 그대로 보기, 결재란에 담당·승인 도장(이름·날짜), **A4 PDF**(한글 글꼴 내장, 한글 금액 "금 구백사십삼만…원정", 품목이 많으면 쪽 나눔·머리글 반복, 쪽번호), **결재 전·반려·취소 발주서는 "효력 없음" 워터마크**, PDF 출력 기록 |
| 발주 상태 관리 | 작성중 → 결재중 → 승인 → 발주전송 → 부분입고 → 입고완료 / 반려 / 종결 / 취소. 승인 후 수정은 **변경 재결재**(작성중으로 되돌리고 개정번호 증가, 다시 대표이사 결재). 입고가 있으면 재결재·취소 불가 |
| 납품·검수 | 승인된 발주서에서 받은 수량만 검수, **부분납품·잔량 자동 계산**, 잔량 초과 검수 차단(화면·서버·DB 제약 3중), 동시 검수 시 초과 입고 방지(행 잠금), 검수 취소(반품) 시 잔량 복원, 잔량 종결, 검수 목록 |
| 대시보드 | 결재할 문서, 미승인 발주서, 발주 확정금액(입고 대기 건수), 검수 완료 공급가액 — 실제 데이터로 집계 |
| 권한 | 현장소장은 배정 현장에만 발주·검수, 대표이사는 조회·결재·PDF, 구매담당 작성·상신·검수, 외부 세무담당 접근 불가 |

## 2. 지시서 22장 필수 테스트 대응 (이번 추가분)

| # | 테스트 | 상태 |
|---|---|---|
| 2 | 발주서 부분납품 및 잔량계산 | ✅ 통과 — 40m 입고 → 잔량 60m, 70m 초과 거부, 60m 입고 시 완료, 검수 취소 시 잔량 복원 |
| 10 | 동시 승인 중복처리 방지 | ✅ 통과 — 대표이사 2명이 4번 동시에 눌러도 승인 1건·감사로그 1건, 남은 잔량 동시 검수 시 1건만 성공 |
| 14 | PDF 생성 | ✅ 통과 — 45개 품목 발주서가 2쪽 이상으로 생성, 결재 전 발주서도 워터마크와 함께 생성 |

## 3. 자동 테스트 결과 (2단계 원문)

```
▶ 자재마스터
  ✔ 자재코드 자동 발급, 같은 코드 중복 거부
  ✔ 엑셀 대량 등록: 미리보기에서 오류 행을 알려 주고, 오류가 있으면 저장하지 않는다
✔ 자재마스터
▶ 발주서 작성 — 서버 금액 계산
  ✔ 품목별 공급가액(원 미만 절사)·과세 품목만 부가세, 합계는 서버가 계산
  ✔ 현장소장은 배정된 현장에만 발주할 수 있다
  ✔ 다른 회사 거래처·현장으로는 발주할 수 없다
  ✔ 수량 0·음수 단가·품목 없음은 거부
✔ 발주서 작성 — 서버 금액 계산
▶ 대표이사 결재
  ✔ 상신하면 결재선이 담당 → 대표이사 승인으로 만들어지고, 결재 중에는 수정할 수 없다
  ✔ 대표이사가 아니면 승인할 수 없다 (최고관리자도 불가)
  ✔ 대표이사 승인 → 발주서 승인, 결재함에서 사라지고, 거래처별 단가가 갱신된다
  ✔ 반려는 사유 필수, 반려 후 수정해 다시 상신하면 새 결재가 만들어진다
  ✔ 보류 후 승인할 수 있고, 기안자는 아무도 처리하지 않은 결재만 회수할 수 있다
  ✔ [필수10] 대표이사 두 명이 동시에 승인을 눌러도 한 번만 처리된다
  ✔ 결재선은 마지막이 대표이사여야 하고, 대표이사가 없는 회사는 상신할 수 없다
  ✔ 결재 기록은 DB에서 삭제할 수 없고, 처리된 단계는 바꿀 수 없다
✔ 대표이사 결재
▶ [필수2] 납품·검수 — 부분납품과 잔량
  ✔ 결재 전 발주서는 검수할 수 없다
  ✔ 40m 부분입고 → 잔량 60m, 초과 70m 거부, 60m 입고 시 해당 품목 완료
  ✔ [필수10] 남은 60m를 두 사람이 동시에 60m씩 검수해도 한 건만 성공
  ✔ 부분입고 잔량 종결, 입고가 있으면 변경 재결재·취소 불가
  ✔ 승인 후 변경은 작성중으로 되돌리고 개정번호를 올려 다시 대표 결재를 받는다
✔ [필수2] 납품·검수 — 부분납품과 잔량
▶ 발주서 PDF
  ✔ 한글 금액 표기
  ✔ 승인된 발주서와 결재 전 발주서 모두 PDF가 만들어지고 출력 기록이 남는다
✔ 발주서 PDF
▶ 대시보드 연결
  ✔ 미승인 발주서 수와 내 결재 대기가 대시보드에 집계된다
✔ 대시보드 연결
▶ [필수1] 공급가액·부가세·합계 계산
  ✔ 공급가액 기준 10% 부가세, 원 미만 절사
  ✔ 합계 기준 역산 시 공급가액 + 부가세 = 합계가 항상 성립
  ✔ 세 값 검증: 합계 불일치와 부가세 오차를 잡아낸다
  ✔ 부동소수점 오차가 없다 (0.1 + 0.2 문제)
✔ [필수1] 공급가액·부가세·합계 계산
ℹ 전체 tests 72 · pass 72 · fail 0
```
