# 이음뷰어 — 플레이 스토어 등록 문구

## 앱 이름 (30자 이내)
이음뷰어 - PDF·캐드(DWG·DXF) 뷰어

## 짧은 설명 (80자 이내)
PDF와 캐드 도면(DWG·DXF)을 휴대폰에서 열고, 치수를 재고, PDF는 편집까지. 인터넷 없이 동작.

## 전체 설명 (4000자 이내)
현장에서 도면과 서류를 바로 확인하는 뷰어입니다. 파일이 서버로 올라가지 않고 휴대폰 안에서만 처리되므로 인터넷 없이, 회사 자료도 안심하고 열 수 있습니다.

■ 캐드 도면 (DWG · DXF)
• AutoCAD 2000~2018 형식의 DWG, DXF 파일 열기
• 레이어 켜고 끄기
• 거리·면적 측정 — 선 끝점에 자동으로 붙어 정확하게
• 도면 단위(mm·cm·m·인치·피트) 선택

■ PDF 보기 · 편집
• 펜, 형광펜, 글 넣기, 도형(사각형·타원·직선·화살표), 도장·서명 이미지 넣기
• 글자 고치기 — 기존 글자를 누르고 새 글자로 바꾸기
• 양식(폼) 입력 — 글 칸, 체크박스, 선택 목록
• 쪽 관리 — 회전, 삭제, 순서 바꾸기, 다른 PDF 끼워넣기(합치기), 일부 쪽만 저장(나누기)
• 축척(1:N) 또는 기준 길이로 보정해 도면 PDF 치수 측정
• 저장(덮어쓰기), 다른 이름으로 저장, 공유

■ 사용 방법
• 앱에서 파일 열기, 또는 파일 관리자·카카오톡에서 PDF/DWG/DXF 파일을 눌러 "이음뷰어"로 열기
• 한 손가락 이동, 두 손가락 확대·축소, 두 번 두드려 확대

■ 안내
• 개인정보를 수집하지 않습니다. 회원 가입·광고가 없습니다.
• 오픈소스(GPL-3.0)로 공개된 앱입니다. 소스: (공개 저장소 주소)
• 아주 큰 도면(수만 개 요소)은 열리는 데 시간이 걸릴 수 있습니다.
