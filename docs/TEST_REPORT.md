## 3. 자동으로 확인하지 못한 것 (직접 확인 필요)

- Android 15·16 기기 (targetSdk 는 36 이지만 에뮬레이터는 Android 14 와 8.0 만 돌렸습니다)

- 실제 기기 전반 (특히 삼성 태블릿 + S Pen 필압, 손바닥 오작동 방지, 저사양 기기 속도)
- 두 손가락 확대·축소 (adb 로 두 손가락 입력을 만들 수 없어 제외)
- 한글 음성 안내 (에뮬레이터에 한국어 음성 없음)
- 효과음·진동
- 보내기(공유), 나만의 색, 자동 색칠, 색칠 추천, 이름 바꾸기, 그림 지우기 – 코드는 들어 있으나 화면에서 눌러 보지 않음
- Android 8~9 의 사진 내보내기 (시스템 파일 선택 화면)
- 7인치·13인치 등 다른 태블릿 크기 (10인치급 한 종류만 확인)
- 저장 공간이 부족한 상황

## 4. 알려진 제한

- 실행 취소 기록은 저장되지 않습니다. 그림을 다시 열면 취소할 수 없습니다.
- 스마트폰 세로 화면에서 붓 도구를 고르면 굵기·진하기 막대가 나타나면서 그림이 약간 작아집니다.
- 스마트폰을 가로로 돌리면 양옆에 도구·색상판이 놓여 그림이 작게 보입니다.
- 화면을 돌리거나 접어 배치가 바뀌면 확대 상태가 '화면 맞춤'으로 돌아갑니다. (그림은 그대로)
- 붓으로만 칠한 칸은 자동 완성 판정에 들어가지 않습니다. ('완성' 버튼으로 완성 처리)
- 큰 이미지 타일 처리: 검토 결과 도안 크기 1536×1536 에서는 필요하지 않아 넣지 않았습니다.
