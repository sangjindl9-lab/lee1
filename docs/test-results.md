## 확인된 앱 권한 (실제 빌드한 APK)
`POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`, `INTERNET`(쇼핑몰 화면 가져오기·규칙 받기용).
ML Kit 사용 통계 전송 구성요소(datatransport)는 매니페스트에서 제거 — 빌드 결과 확인 “없음”. 제거 후에도 글자 인식 기기 테스트 8개 통과.
