## 요약
- **실장비 시험: 0건 수행.** 실제 IP 카메라가 없는 환경이라 모든 카메라 연동은 합성 스트림·시뮬레이터로만 시험했습니다.
- **브라우저 실시간 보기(WebRTC/HLS): 미검증.** 검증 환경에서 MediaMTX 공식 바이너리·이미지 다운로드가 차단되어 실행하지 못했습니다.
  토큰 발급·인증 훅·설정 생성은 자동화 시험을 통과했지만, 실제 브라우저 ↔ MediaMTX 영상 경로는 확인하지 못했습니다.
- 녹화·복구·검색·내보내기·권한·보안 항목은 합성 스트림 + 자동화 시험으로 통과했습니다.

구분: **합성** = GStreamer 합성 RTSP 카메라/ONVIF 시뮬레이터로 실제 프로세스를 돌려 시험 · **자동화** = pytest(실제 PostgreSQL) · **실장비** = 실제 카메라

### 2·3단계 실장비 확인 목록
1. 실제 PTZ 카메라로 연속 이동·정지 지연, 프리셋, 속도
2. 제조사별 ONVIF 이벤트 토픽(모션·가림·알람 입력) 수신과 구독 갱신 주기
3. 현장 LAN 에서 discovery 서비스(host 네트워크) 탐색
4. 실제 SMTP(회사 메일) 알림 전송
5. 현장 2곳 이상 + 중앙 1대 Edge 보고(인터넷 경유)
6. 이벤트 녹화 시 실제 카메라 GOP(키프레임 간격)에 따른 사전 구간 정확도
