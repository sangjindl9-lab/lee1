개인정보처리방침

시행일: 2026년 11월 22일 · 이음소프트웨어

1. 수집하는 정보

  • 계정: 이메일 주소, 이름(선택), 비밀번호(복원할 수 없는 해시로만 저장)
  • 기기: 기기 이름·모델·운영체제·앱 버전, 앱 설치 식별자, 마지막 접속 시각·IP 주소
  • 연결·기록: PC 연결 승인 내역과 허용 폴더 경로, 로그인·연결·원격 작업 기록(파일 경로, 크기, 시각)

파일 내용은 수집·저장하지 않습니다. PC와 휴대폰 사이의 파일은 암호화된 연결(TLS)로 서버를 거쳐 전달될 뿐 서버에 보관되지 않습니다.

2. 이용 목적

회원 식별과 로그인, 기기 간 연결 및 파일 전송 중계, 보안(비정상 로그인 탐지, 접근 기록), 고객 문의 대응, 서비스 개선.

3. 보관 기간

계정 삭제 시 계정·기기·연결·기록 정보를 즉시 삭제합니다. 접근 기록은 보안 목적으로 최대 1년간 보관 후 삭제합니다.

4. 제3자 제공 및 처리 위탁

법령에 따른 경우를 제외하고 제3자에게 제공하지 않습니다. 서버 운영을 위해 Railway(미국, 클라우드 호스팅)와 GitHub(설치 파일 배포)를 이용합니다.

5. 이용자의 권리

앱의 PC 연결 → 계정 메뉴에서 언제든 로그인 기기 확인·차단, 계정 삭제를 할 수 있습니다. 열람·정정 요청은 pm999@naver.com 으로 해 주세요.

6. 안드로이드 앱의 파일 접근

파일 관리자 2는 파일을 보여주고 정리하기 위해 '모든 파일에 대한 접근' 권한을 사용합니다. PC 연결 기능은 사용자가 승인한 폴더 안의 파일만 PC에 전달하며, 다른 앱의 비공개 저장소에는 접근하지 않습니다.

7. 클라우드 연동 (선택)

Google Drive·Dropbox·OneDrive를 연결하면 해당 서비스가 발급한 접근 토큰과 계정 이메일(표시용)을 저장합니다. 토큰은 AES-256으로 암호화해 보관하며, 연결 해제 또는 계정 삭제 시 즉시 삭제합니다. 클라우드 서비스의 비밀번호는 저장하지 않습니다. 파일 내용은 사용자가 받거나 올릴 때 서버를 거쳐 전달될 뿐 서버에 저장하지 않습니다. Google 사용자 데이터는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

8. 외부 공유 링크 (선택)

사용자가 공유 링크를 만들면 파일 이름·크기·유효 기간·받은 횟수와, 받는 사람의 접속 IP·시각을 기록합니다. 파일은 서버에 복사되지 않고 받는 순간 휴대폰 또는 클라우드에서 전달됩니다. 링크는 언제든 해제할 수 있습니다.

9. NAS 연결 (PC 프로그램)

NAS 주소·아이디는 PC에만, 비밀번호는 Windows 자격 증명 관리자에만 저장되며 서버로 전송되지 않습니다. NAS와의 파일 전송은 PC와 NAS 사이에서 직접 이루어집니다.
