# 사용자 매뉴얼

## 1. 시작
1. `/signup` 에서 회사명·이름·이메일·비밀번호(8자 이상)로 가입 → 가입자는 회사 **관리자**가 됩니다.
2. [＋ 새 프로젝트] → 프로젝트명과 **산업 분야**(금형 / 기계·산업장비 / 전기·정보통신 / 건축·건설 / 일반 제품) 선택.

## 2. 화면 구성
- **상단**: 프로젝트 · 파일 업로드 · 3D 변환 · 분해도 · 동영상 제작 · 공유 탭, [저장](Ctrl+S), 다크/라이트
- **좌측**: 모델 목록, 부품 트리(검색, 클릭=선택, 더블클릭=격리, ●=숨김)
- **중앙**: 3D 뷰어 — 마우스 왼쪽 드래그 회전, 휠 확대·축소, 오른쪽 드래그 이동 / 터치: 한 손가락 회전, 두 손가락 확대·이동
  - 도구: 등각·정면·후면·좌측·우측·상부·하부 보기, 원근/직교, 자동회전, 투시(전체 투명화), 와이어프레임, 단면(X/Y/Z·위치·반전), PNG 저장, 전체 화면
- **우측**: 선택 부품 속성(크기·중심·체적·색상·투명도·숨김·격리·분해 방향/거리/단계·설명) + 현재 탭 도구
- **하단**: 타임라인(재생/처음으로/구간 이동), 분해 슬라이더

## 3. 파일 업로드 · 3D 변환
- 지원: **STEP/STP, IGES/IGS, STL, GLB, DXF** (드래그 앤 드롭, 여러 개 가능, 대용량 분할 업로드)
- STEP·IGES·STL·GLB 는 자동 변환 → 모델 목록에 나타납니다. STEP 의 조립 계층·부품명·색상이 그대로 부품 트리가 됩니다.
- STL 은 부품 구조가 없어 1개 부품으로 표시됩니다(자동 분리 안 됨).
- **DXF**: 업로드 후 [두께 입력 → 3D 생성]. 창에서 인식된 단위·레이어·윤곽·치수(외곽 일치 여부)를 확인하고 **두께(mm)를 직접 입력**해야 생성됩니다. 2D 도면에는 깊이 정보가 없기 때문에 프로그램이 임의로 정하지 않습니다.
  - 형상 근거 표시: ■녹색=원본 도면에서 확인, ■노랑=사용자 입력으로 확정, ■보라=AI 추정(현재 없음)
- 같은 이름 파일을 다시 올리면 v2, v3… 로 버전이 쌓이며 원본은 보존됩니다.

## 4. 분해도 · 조립 애니메이션
1. [분해도] 탭: 처음에는 조립체 중심 기준 **방향 제안**이 자동 적용됩니다(가장 큰 부품 고정, 볼트·핀은 축 방향, 작은 체결부품부터 1단계). *충돌 검토는 하지 않으므로 필요한 부품은 직접 고치세요.*
2. 부품을 선택 → 우측 [분해 설정]에서 방향(±X/±Y/±Z), 이동 거리, 분해 단계(0=고정) 수정
3. 하단 분해 슬라이더 또는 [전체 분해]/[조립 상태]로 확인, [여기까지 분해]로 단계별 확인
4. ▶ 재생: 장면 구성(정지→분해→회전→조립…) 순서로 애니메이션
5. [저장] — 저장할 때마다 장면 버전이 쌓입니다([프로젝트] 탭에서 확인)

## 5. 동영상(MP4) 제작
1. [동영상 제작] 탭 → 장면 구성: 클립(정지·분해·조립·360° 회전) 추가/삭제/순서/길이/회전각
2. 배경(스튜디오·다크·화이트·공장), 모드(홍보 쇼룸/기술 검토), 제품명·설명 자막, 워터마크(비우면 회사명)
3. 원하는 화면으로 돌려 놓고 [현재 시점을 영상 카메라로] (없으면 자동 등각 시점)
4. 해상도(HD·Full HD·QHD·4K)와 fps(24·30·60) 선택 → [MP4 렌더링 시작] — 진행률이 표시되고 완료되면 목록에서 재생·[MP4 다운로드]
5. 실패하면 원인과 [재시도] 버튼이 표시됩니다. 영상 길이 최대 120초(관리자 설정).

## 6. 웹주소(URL) 공유
1. [공유] 탭 → 제목·비밀번호(선택)·만료일(선택) → [공유 링크 만들기] (현재 장면이 저장된 뒤 공유)
2. 주소 복사·열기, **QR코드**(PNG 저장), **iframe 코드 복사**(홈페이지 삽입), 방문 수 확인
3. [재발급]: 기존 주소를 폐기하고 새 주소 발급 / [폐기]: 즉시 접속 차단
4. 받는 사람은 로그인·CAD 프로그램 없이 PC·스마트폰 브라우저에서 회전·확대·부품 목록·부품 설명·분해/조립·애니메이션 재생을 할 수 있습니다. **원본 CAD 파일은 공개되지 않습니다.**
