# 프로젝트일정표 — 제품 요구 문서(PRD)

## 1. 제품 개요

**프로젝트일정표**는 보할(步割) 방식으로 프로젝트 일정을 계획하고 진척을 관리하는 웹 애플리케이션입니다.

보할 방식이란 프로젝트를 구성하는 각 공종(작업)에 전체 대비 비중(보할, %)을 부여하고, 그 비중을 작업 기간에 배분하여 **기간별 계획 공정률**과 **누계 공정률**을 산출하는 일정 관리 기법입니다. 실제 진척을 입력하면 같은 기준으로 **실적 공정률**이 계산되어 계획 대비 실적을 수치와 곡선(S-Curve)으로 비교할 수 있습니다.

이 제품은 엑셀로 수작업하던 보할 공정표를 대체합니다. 공종과 금액(또는 가중치), 기간만 입력하면 보할·기간별 공정률·누계·S-Curve가 자동 계산됩니다.

### 용어

| 용어 | 뜻 |
|---|---|
| 공종 | 일정표의 한 행을 이루는 작업 단위 |
| 보할(%) | 전체 프로젝트에서 해당 공종이 차지하는 비중. 전 공종의 합은 100% |
| 계획 공정률 | 보할을 작업 기간에 배분해 산출한 기간별 계획 진척 비율 |
| 실적 공정률 | 공종별 실제 진척률에 보할을 곱해 합산한 실제 진척 비율 |
| 누계 | 프로젝트 시작부터 해당 기간 말까지의 합계 |
| 기준일 | 계획과 실적을 비교하는 날짜(기본값: 오늘) |
| S-Curve | 계획 누계와 실적 누계를 시간축에 그린 곡선 |

## 2. 목표와 비목표

### 목표
- 공종·금액·기간 입력만으로 보할 공정표가 자동 생성된다.
- 월별/주별 계획 공정률과 실적 공정률, 누계를 한 화면에서 확인한다.
- 기준일 현재 계획 대비 실적 편차(앞섬/지연)를 즉시 알 수 있다.
- 설치형 외부 서비스 없이 PC 한 대에서 실행된다.

### 비목표(이번 범위에서 제외)
- 로그인·권한 관리, 다중 사용자 동시 편집
- 선후행 관계(CPM) 기반 자동 일정 계산, 자원 평준화
- 휴일·작업일 달력을 반영한 배분
- 외부 배포, 클라우드 동기화

## 3. 사용자

| 사용자 | 상황 | 필요 |
|---|---|---|
| 공사·프로젝트 관리자(PM, 공무 담당) | 착수 시 공정표를 작성하고 매월 공정률을 보고한다 | 금액 기준 보할 자동 계산, 월별 계획/실적 표, 출력 가능한 공정표 |
| 팀 리더·실무 담당자 | 담당 작업의 진척을 주기적으로 갱신한다 | 공종별 진척률을 빠르게 입력 |
| 발주자·경영진(열람자) | 진행 상황을 보고받는다 | 계획 대비 실적 편차와 S-Curve를 한눈에 확인 |

로그인이 없으므로 위 구분은 역할 설명이며, 화면 접근에 차이는 없습니다.

## 4. 핵심 사용 흐름

### 흐름 1 — 공정표 작성
1. 프로젝트 목록 화면에서 **새 프로젝트**를 눌러 이름, 시작일, 종료일, 보할 기준(금액/가중치)을 입력한다.
2. 프로젝트 상세 화면의 **공종 관리** 탭에서 공종을 추가한다. 공종마다 구분, 공종명, 금액(또는 가중치), 시작일, 종료일을 입력한다.
3. 공종을 저장할 때마다 각 공종의 보할(%)이 다시 계산되어 표에 표시되고, 합계가 100%로 표시된다.
4. **보할 공정표** 탭으로 이동하면 공종별 막대(간트)와 기간별 계획 공정률, 하단의 기간 계획·누계 계획 행이 자동으로 채워져 있다.

### 흐름 2 — 실적 입력과 진도 확인
1. 공종 관리 탭에서 공종의 **실적 입력**을 눌러 날짜와 그 날짜까지의 누계 진척률(0~100%)을 입력한다.
2. 보할 공정표 탭 하단에 기간 실적·누계 실적 행이 갱신된다.
3. 상단 요약 카드에서 기준일 현재 계획 누계, 실적 누계, 편차(%p)와 상태(정상/지연/앞섬)를 확인한다.
4. **S-Curve** 영역에서 계획 곡선과 실적 곡선을 비교한다.

### 흐름 3 — 보고
1. 보할 공정표 탭에서 기간 단위(월/주)와 기준일을 선택한다.
2. **CSV 내려받기**로 표를 파일로 받거나 **인쇄**로 공정표를 출력한다.

## 5. 성공 기준
- 공종 10개 규모의 공정표를 5분 안에 작성할 수 있다.
- 계산된 보할과 누계 공정률이 수기 계산값과 소수 둘째 자리까지 일치한다.
- 서버를 재시작해도 입력한 데이터가 유지된다.
