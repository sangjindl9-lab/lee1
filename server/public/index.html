휴대폰과 PC, 클라우드의
모든 파일을 하나로 연결하세요.

파일 관리자 2 PC CONNECT로 PC에서 휴대폰 사진·동영상·문서를 바로 보고, 끌어다 놓아 주고받으세요. 같은 계정으로 로그인하고 휴대폰에서 한 번 승인하면 됩니다.

⬇ PC 프로그램 다운로드 (Windows·macOS·Linux) 설치·연결 방법
📱

PC에서 휴대폰 파일 탐색

허용한 폴더의 사진·동영상·문서·다운로드를 PC 화면에서 그대로 봅니다.

⇅

양방향 전송

휴대폰 → PC 다운로드, PC → 휴대폰 업로드. 진행률과 속도를 실시간으로 표시합니다.

🔐

휴대폰이 승인해야만 연결

같은 계정이어도 휴대폰에서 승인하고 허용한 폴더만 열립니다. 언제든 연결 해제.

🌐

어디서나 연결

같은 Wi-Fi가 아니어도 인터넷만 되면 연결됩니다. 모든 통신은 암호화(HTTPS·WSS)됩니다.

이렇게 연결해요

  1. 휴대폰에 파일 관리자 2 앱을 설치하고 PC 연결 메뉴에서 로그인합니다.
  2. PC(Windows·macOS·Linux)에 프로그램을 설치하고 같은 계정으로 로그인합니다.
  3. PC에서 휴대폰을 선택하고, 휴대폰에서 연결을 승인하며 허용할 폴더를 고릅니다.
  4. PC에서 휴대폰 파일을 탐색하고 주고받습니다.
