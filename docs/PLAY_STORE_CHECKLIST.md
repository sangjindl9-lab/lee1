# Google Play 배포 준비 (아동 대상 앱)

이 문서는 배포 전에 Play Console 에서 직접 확인·입력해야 하는 항목을 정리한 것입니다.
정책은 수시로 바뀌므로 **제출 직전에 Play Console 정책 센터의 최신 "가족 정책"을 다시 확인**해야 합니다. 이 문서는 법률 자문이 아닙니다.

## 앱이 이미 지키고 있는 것 (코드로 확인 가능)

| 항목 | 상태 |
|---|---|
| 권한 | 매니페스트에 권한 없음 (인터넷·카메라·위치·연락처·저장소 모두 없음) |
| 광고 | 없음. 광고 SDK 미포함 |
| 분석·추적 SDK | 없음 |
| 회원가입·로그인 | 없음 |
| 외부 링크 | 없음 |
| 앱 밖으로 공유 | 보호자 확인(곱셈 문제) 뒤에만 가능 |
| 부모님 메뉴 | 보호자 확인 뒤에만 진입 |
| 데이터 저장 | 기기 안 앱 전용 저장 공간만 사용, `allowBackup=false` |
| targetSdk | 35 |

## Play Console 에서 입력할 것

1. **앱 콘텐츠 → 타겟층 및 콘텐츠**: 대상 연령(예: 5세 이하, 6~8세, 9~12세) 선택. 어린이를 대상에 넣으면 가족 정책이 적용됩니다.
2. **데이터 보안(Data safety)**: "수집하는 데이터 없음, 공유하는 데이터 없음"으로 신고. (앱이 실제로 아무것도 전송하지 않음)
3. **광고**: "광고 없음" 선택.
4. **개인정보처리방침 URL**: `docs/PRIVACY_POLICY.md` 초안의 연락처·시행일을 채워 웹에 게시한 주소를 입력. 어린이 대상 앱은 방침 URL 이 필수입니다.
5. **콘텐츠 등급**: 설문 작성 (폭력·성적 콘텐츠 등 없음).
6. **앱 액세스 권한**: 로그인 없이 모든 기능 사용 가능이라고 표시.
7. **스토어 등록정보**: 앱 이름, 짧은 설명, 자세한 설명, 아이콘(512px), 그래픽 이미지(1024×500), 휴대전화·7인치·10인치 태블릿 스크린샷.
8. **AI 생성 콘텐츠**: 도안 30장은 Higgsfield(GPT Image 2.6)로 생성했습니다. 스토어 설명에 AI 생성 도안임을 밝히는 것을 권장합니다.

## 배포 전에 사람이 해야 하는 검토 (미완료)

- [ ] **Higgsfield 상업적 이용 조건 확인**: 현재 요금제(starter)와 사용 모델(GPT Image 2.6)의 약관에서 상업적 이용이 허용되는지 확인.
- [ ] **유사 캐릭터 검토**: 30장 각각이 기존 유명 캐릭터와 혼동될 만큼 닮지 않았는지 사람이 직접 확인. (프롬프트에는 기존 캐릭터 이름·작품명을 쓰지 않았습니다.)
- [ ] **상표 검토**: 앱 이름 "이음 키즈 컬러링 / EUM KIDS COLORING" 상표 검색.
- [ ] AI 생성물은 독점 저작권이 자동으로 보장되지 않을 수 있음을 전제로 사업 판단.
- [ ] 검토를 마치면 `tools/pipeline.py` 의 `licenseReview` 값을 `done` 으로 바꾸고 다시 실행 (부모님 메뉴의 "검토 전" 표시가 "완료"로 바뀝니다).
- [ ] 개인 개발자 계정이면 비공개 테스트(테스터 12명, 14일) 뒤 프로덕션 신청.
- [ ] 실제 기기 테스트 (특히 삼성 태블릿 + S Pen 필압, 손바닥 오작동).
