## 4. 아직 구현하지 않은 것

**2단계 이후 기능** — 메뉴에는 보이지만 "N단계" 표시와 함께 안내 화면으로만 연결됩니다. 겉모습만 만든 화면은 없습니다.

|---|---|
| 2 | 자재마스터(엑셀 대량등록), 구매요청·발주서(PDF 양식 템플릿), 납품·검수·부분납품, 지급결의, 전자결재(다단계·금액별 결재선·결재 도장), 복식부기 전표·자동분개·역분개, 원장·시산표·재무제표, 월마감·기간 잠금, 실행예산 공종·원가항목 분할, 현장 손익, PDF 출력 |
| 3 | 팝빌/바로빌 Adapter(Sandbox), 홈택스 수집, 국세청 사업자 상태조회, OCR/AI 문서 스캔, 발주·검수·계산서 대사 |

| 5 | 은행·카드(엑셀 업로드 → API), 거래내역 대사, 자금일보, 나라장터, 외부용 REST API 키·웹훅·Idempotency Key, 백업 관리 화면 |

**1단계 안에서 남은 보완점**

- 파일 저장소는 로컬 디스크 어댑터만 있습니다. S3 호환(MinIO 등) 어댑터는 같은 인터페이스로 추가하면 됩니다.
