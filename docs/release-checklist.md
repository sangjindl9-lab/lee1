# 출시 체크리스트 (출시 준비 ≠ 실제 게시)

> 기준일 2026-11-21. **스토어 등록·심사·게시는 하지 않았음.** 승인 없이 게시하지 말 것.
> Play 정책은 바뀌므로 제출 직전에 Play Console 안내를 다시 확인할 것.

## 1. 빌드 구분
| 구분 | 상태 | 비고 |
|---|---|---|
| 사내 테스트 APK (디버그 서명) | ✅ Actions에서 자동 빌드 → 릴리스 `eum-purchase-note-latest` | 스토어 업로드 불가 |
| 스토어 배포용 AAB (업로드 키 서명) | ❌ 미완료 | 업로드 키 생성·보관, `bundleRelease` 서명 설정 필요. Play 앱 서명 사용 권장 |
| 대상 API | ✅ targetSdk 36 | 2026-08-31부터 신규 앱·업데이트는 API 36 이상 필요 |

## 2. Google Play 공통 (모든 국가)
- [ ] 개인 개발자 계정(2023-11-13 이후 생성) → **비공개 테스트 12명 이상, 14일 연속 참여** 후 프로덕션 신청 (도플리 테스터 목록 활용 가능)
- [ ] 앱 이름·간단한 설명·자세한 설명 4개 언어 입력 (`docs/store-listing.md`)
- [ ] 개인정보처리방침 URL 입력 — 페이지 게시됨: `https://eum-purchase-note-production.up.railway.app/ko/privacy.html` (en/ja/es 동일 경로)
- [ ] **데이터 보안(Data safety)** 양식: 아래 3항 참고
- [ ] **타깃 연령·콘텐츠**: ‘10대가 읽기 쉽다’ ≠ ‘어린이 대상 출시’. 권장 = **13세 이상(어린이 미포함)** 으로 신고. 어린이(13세 미만)를 대상에 넣으면 가족 정책·교사 승인 등 추가 요건이 붙음 → 별도 결정 필요
- [ ] 콘텐츠 등급(IARC) 설문 — 사용자 간 소통·위치·구매 기능 없음
- [ ] 광고 포함 여부: 없음 / 인앱 결제: 없음
- [ ] 앱 액세스: 로그인 없음(모든 기능 바로 사용)
- [ ] 스크린샷(언어별)·피처 그래픽·512 아이콘 — 미완료
- [ ] 정확 알람 권한 사용 안 함(일반 알람) → 별도 신고 불필요. 절전 시 알림 지연 가능성은 앱·설명에 안내됨
- [ ] 판매자 정보: 무료 앱이라도 EU 배포 시 ‘거래자(trader) 여부’ 신고 필요 → 아래 국가별 참고

## 3. 데이터 보안 신고 초안 (실제 APK 기준, 검수표의 권한 확인 결과와 일치해야 함)
| 항목 | 답 | 근거 |
|---|---|---|
| 데이터 수집 | 수집하지 않음(운영자에게 전송되는 사용자 데이터 없음) | 구매 기록·사진은 기기 안에만 저장. 서버·분석 SDK 없음 |
| 인터넷 사용 | 쇼핑몰 화면 가져오기(앱 안 브라우저) + 가져오기 규칙 받기 | 브라우저는 사용자가 고른 쇼핑몰 사이트와만 통신. 규칙 요청에는 개인정보 없음 |
| 데이터 공유 | 공유하지 않음 | 동일 |
| 기기 내 처리 | 구매 정보·사진·인식 글자·가져온 주문 | Room DB + 앱 전용 폴더, 자동 클라우드 백업 제외 |
| 삭제 요청 | 앱 안 ‘모든 데이터 삭제’, ‘쇼핑몰 로그인 정보 지우기’ | 설정 화면 |
| 포함 라이브러리 | Google ML Kit(기기 내 글자 인식) | 사용 통계 전송 구성요소를 매니페스트에서 제거(빌드 결과로 확인) |
| 확인 필요 | 앱 안 브라우저(WebView)로 사용자가 쇼핑몰을 여는 것이 ‘수집’에 해당하지 않는지 | 제출 직전 Play Console 데이터 보안 안내 재확인 |

## 4. 국가별
| 국가 | 스토어 언어 | 확인할 것 | 상태 |
|---|---|---|---|
| 대한민국 | ko-KR | 개인정보 처리방침 한국어 게시 ✅ / 무료·결제 없음 → 통신판매업 신고 대상 여부는 유료화 시 재검토 / 위치·연락처 수집 없음 | 준비 중 |
| 미국 | en-US | COPPA: 어린이 대상 아님으로 신고 / 데이터 보안 양식 | 준비 중 |
| 일본 | ja-JP | 個人情報保護法: 수집 없음 명시 ✅ / 일본어 화면·스크린샷 | 준비 중 |
| 스페인·EU | es-ES | GDPR: 수집 없음 명시 ✅ / **DSA 거래자 여부 신고**(개인 계정·무료 앱이면 ‘비거래자’ 가능 여부를 Play Console 안내로 확인) | 확인 필요 |
| 멕시코·중남미 | es-419 | 스페인어 문구 공용 가능. 통화 기호 `$`는 앱에서 MXN/USD 등을 사용자가 고르게 되어 있음 ✅ | 준비 중 |
| 그 외 국가 | 영어(기본) | 앱은 영어로 시작. 해당 국가 법·심사는 별도 확인 전까지 배포 국가에서 제외 권장 | 미검토 |

- 번역이 있다고 해당 국가 출시가 끝난 것은 아님. 국가 선택은 Play Console ‘국가/지역’에서 따로 한다.

## 5. 쇼핑몰 화면 가져오기 관련
- [ ] 쿠팡·네이버·아마존 **실제 계정으로 주문 내역 가져오기 확인** (합성 화면 글자로만 테스트함)
- [ ] 각 쇼핑몰 이용약관에서 앱 안 브라우저 사용·화면 읽기 관련 조항 확인
- [ ] 화면이 바뀌어 안 될 때: `tools/gen_rules.py` 수정 → version 올리기 → push (앱은 Railway에서 새 규칙을 받아 씀, 앱 업데이트 불필요)

4. Play Console 앱 생성 → 비공개 테스트 → 12명·14일 → 프로덕션 신청
