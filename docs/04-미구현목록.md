# 미구현·제약 목록 (v0.2.0, 2026-10-31)

화면에서는 아래 기능을 작동하는 것처럼 표시하지 않습니다.

## 아직 만들지 않은 것
| 기능 | 상태·필요한 것 |
|---|---|
| 제조사 전용 드라이버(Hanwha SUNAPI, Hikvision ISAPI, Axis VAPIX, Dahua) | **미구현.** 드라이버 레지스트리에 ‘미지원’으로 표시. 대상 모델·펌웨어 실장비와 공식 문서(Hikvision·Hanwha 는 파트너 계정 필요)를 확보해야 함. 그 전에는 ONVIF·RTSP 로 등록 |
| 카메라 저장영상 회수(Profile G) | 검색·재생 주소 조회까지만. ONVIF Replay(RTSP `Require: onvif-replay`, `Range: clock=`)를 처리하는 전용 수신기가 필요해 미구현 |
| Profile M(메타데이터 스트림) | 이벤트 토픽 중 분석 이벤트만 구분. 메타데이터 스트림 수신·표시는 미구현 |
| 자체 AI 분석(사람·차량·침입·선 넘기) | **미포함.** 외부 분석 모듈이 이벤트를 보내는 연동 API 만 제공 |
| 장애 전환(대체 녹화 서버) | 미구현. 무중단·무손실을 보장하지 않음. 현재는 서비스 자동 재시작·재연결·미확정 구간 복구까지 |
| 양방향 음성(카메라로 말하기) | 미구현 |
| 시청용 코덱 변환(H.265→H.264, AAC→Opus) | 미구현. H.265 는 브라우저 지원 범위만, AAC 음성은 HLS 에서만 재생 |
| 중앙에서 현장 영상 직접 중계 | 미구현. 중앙은 상태만 받고, 영상은 현장 서버 주소(VPN 등)로 접속 |
| NAS 녹화 | 미검증 |
| MJPEG·RTMP·SRT 입력 | 미지원 |
| 2단계 인증(OTP) | 미구현 |

## 구현했지만 제약이 있는 것
| 항목 | 내용 |
|---|---|
| 음성 권한 | 권한이 없으면 화면에 버튼이 없고 WebRTC 음성 트랙을 요청하지 않음. 단, HLS 재생 시 스트림에 음성이 포함되므로 브라우저 개발자 도구로는 들을 수 있음(서버에서 음성을 제거하는 변환은 미구현) |
| 이벤트 녹화 정밀도 | 10초 구간 단위로 확정 → 실제 녹화는 요청한 전·후 시간보다 최대 10초 더 길 수 있음. 사전 구간은 카메라 키프레임 간격에 영향 받음 |
| 이벤트 녹화 버퍼 | 이벤트 대기 중에도 영상을 받아 최대 2분 임시 저장하므로 카메라 연결·네트워크 부하는 연속 녹화와 같음(디스크 사용만 줄어듦) |
| 끝나지 않는 이벤트 | 장치 오류로 이벤트가 닫히지 않아도 녹화는 시작 후 30분까지만 확정 |
| PTZ 감사로그 | 연속 이동 명령은 사용자·카메라별 1분에 한 번만 기록 |
| 자동 탐색 | 같은 L2 망에서만 동작. 라우터·VPN 너머는 수동 등록 |
| 강제 로그아웃 | 새 연결은 즉시 거부, 이미 열린 WebRTC 세션은 창을 닫거나 재연결할 때 차단(토큰 수명 10분) |
| 녹화 시각 | 서버 시계 기준 ±1~2초 |
| 원본 복사 내보내기 | 직전 키프레임부터 시작(결과에 실제 시작 시각 표시) |
| 공간 기준 정리 | 디스크 전체 여유 기준. 전용 디스크 권장 |
| ONVIF | 연동 구현이며 공식 적합성 인증과 무관 |
