## 화면 확인: 실제 브라우저(Chromium)로 실행

빌드한 서버를 띄우고 자동화 브라우저로 아래를 끝까지 실행했다. 브라우저 오류는 없었다.

- 판매자 가입·등록 → 운영자 추가 인증·승인 → 계좌 등록(재인증)·확인 → 상품 등록 → 버전 생성 → 파일 2개 업로드 → 심사 제출 → 승인
- 구매자 가입 → 구매 조건 확인 → 테스트 결제 → 거래 작업실 상태 확인 → 다운로드(받은 파일이 원본과 같은 크기) → 구매확정
- 운영자 지급 요청 → 이체 완료 시뮬레이션 → 대사(불일치 0) → 통계(총 거래액 350,000원, 순수수료 35,000원, 지급 290,070원)
- 제3자의 주문 접근 차단, 위조 다운로드 링크 403
- 맞춤 개발: 의뢰 → 견적 → 계약 동의 → 단계 결제 → 증빙만으로 납품 거부 → 정상 납품
- 지식재산권: 등록 → 심사 → 열람 요청(승인 전 403) → 상담 → 조건 제시·동의 → 결제 → 독점 잠금 → 증빙 없는 도메인 인도 표시 거부
- 모바일 폭(390px)에서 가로 넘침 없음
