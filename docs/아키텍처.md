# 기술 구조 설계

## 1. 구성
| 계층 | 선택 | 이유 |
|---|---|---|
| 서버 | Node.js 22 + Express 5 | 단일 프로세스 독립 설치, 화면과 계산 모듈 공유 |
| DB | SQLite (better-sqlite3, WAL) | 별도 DB 서버 없이 설치. 트랜잭션·낙관적 잠금 지원 |
| 세션 | express-session + SQLite 저장소 | 서버 재시작 후에도 로그인 유지, httpOnly 쿠키 |
| 화면 | 바닐라 JS ES 모듈 + SVG | 빌드 단계 없음, 대형 도면에서 벡터 렌더링 |
| 계산 | `shared/*.js` (UMD) | **화면·PDF·Excel·검증이 같은 코드**로 길이·물량·검토 계산 |
| PDF | pdfkit + Noto Sans KR 내장 | 벡터 출력, 한글 글꼴 누락 없음 |
| Excel | exceljs | 산출표 시트별 출력, 엑셀 일괄 등록 |
| CAD | dxf-parser(DXF), LibreDWG/ODA(DWG→DXF 외부 실행) | DXF는 자체 해석, DWG는 변환 엔진 연동 계층 |
| PDF 입력 | poppler `pdfinfo`/`pdftoppm` | 쪽 수 판독·썸네일·배경 래스터화 |

동시 사용자는 같은 서버에 접속하며, 저장 단위는 객체별 버전(`ver`)으로 충돌을 감지합니다.

## 2. 데이터 모델 (server/migrations/001_init.sql)
```
companies ─< users
companies ─< projects ─< project_members(user, role)
projects ─< sheets(도면) ─< sheet_revisions(개정 스냅샷: 객체+물량표)
projects ─< files(원본·변환 결과, 형식 판독 메타)
projects ─< devices   (장비: type, tag, 좌표, props, field, sch)
projects ─< cables    (물리 케이블 구간: kind, product, from/to {dev,port}, points, parent_id)
projects ─< conduits  (관로·트레이 구간: product, points, method)
projects ─< annotations (문자·치수·인출선·측정·검토영역)
products  (제품 사양: 케이블·관로·부속·장비 – 임피던스, 외경, 감쇠표, 권장거리+근거, 코어 수 …)
attachments (현장사진·시공사진·사양서·시험결과) · change_log(변경자·시간·사유·전후값) · jobs(비동기 변환) · settings
```

### 화면의 선 / 물리 케이블 / 논리 회선 구분
| 개념 | 저장 | 설명 |
|---|---|---|
| 화면 선 | `cables.points` | 도면 좌표 폴리라인. 끝점은 연결 장비 위치를 따라감 |
| 물리 케이블 | `cables` 레코드 (+ `parent_id` 연속 구간) | **구매 물량 단위.** 여러 도면에 걸치면 연속 구간을 합산해 1조로 집계 |
| 논리 회선 | 계산 뷰 `CCTVCalc.circuits()` | 카메라 → (접속점·보호기·중계기·발룬·연결참조) → DVR/스위치/전원장치 를 그래프로 추적 |
| 포트 | `CCTVCatalog.portsFor(device)` | 장비 유형·포트수 속성에서 생성 (CH1…, P1…, SFP1…, OUT1…). 사용자 추가 포트 가능 |
| 녹화 채널 | 동축: DVR 입력 포트(물리) / IP: `props.nvr_id + nvr_channel`(논리) | |

### 복합케이블
한 `cables` 레코드(kind=`composite`)에 영상 끝(`from/to`)과 전원부 끝(`props.power_from_dev/port`, `power_to_dev/port`)을 함께 저장합니다. 회선 추적에서는 영상 회선·전원 회선 두 개로 보이지만 **물량은 복합케이블 길이로 1회만** 집계되고, 전원케이블·동축케이블 물량에는 포함되지 않습니다. 분리 인입 길이(`split_tail_*_m`)는 같은 케이블 길이에 더하고, 별도 연장선은 별도 케이블로 작성합니다. 관로 점유율에는 복합케이블 실제 외경을 사용합니다.

### 내부 ID와 표시번호
모든 객체는 UUID(`id`)로 연결되고 `tag`(CAM-01 등)는 표시용입니다. 번호를 바꾸거나 엑셀로 일괄 수정해도 연결이 유지됩니다.

## 3. 좌표 체계
| 좌표 | 정의 |
|---|---|
| 이미지 좌표 | 원본 배경의 픽셀(이미지) / 150dpi 래스터 픽셀(PDF) / CAD 단위(DXF·DWG, Y축 반전·원점 이동) |
| 도면 좌표 | 배경 좌표에 도면 회전(0/90/180/270°)을 적용한 좌표. **모든 설계 객체는 도면 좌표로 저장** |
| 화면 좌표 | 도면 좌표 × 확대율 + 이동량 (SVG `matrix`). 확대·축소 시 객체 좌표는 변하지 않음 |

- 축척: `scale.upm` = 실제 1m 당 도면 단위. 두 점 보정(mm·cm·m 입력 → 내부 m 환산) 또는 CAD 단위(mm→1000) 후 확인.
- 축척이 없으면 모든 길이·물량·화각 거리는 "확인 필요"로 표시하고 숫자를 확정하지 않습니다.
- CAD 원좌표 복원: `X = x + origin.x`, `Y = origin.y − y` (DXF 내보내기에서 사용).
- 지리좌표: 사용자가 입력한 기준점(도면 X,Y ↔ 위도·경도)만 저장. 기준점이 없으면 GPS 좌표를 만들지 않습니다.
- 도면 회전: 배경과 함께 모든 객체·카메라 방향을 같은 변환으로 회전.
- 개정 정합: 이전/새 배경에서 같은 기준점 2쌍 → 닮음변환(배율·회전·이동)을 모든 객체에 적용, 축척도 배율만큼 보정, 장비마다 "개정 위치 검토 필요" 표시.

## 4. 파일 처리
| 형식 | 판독 | 사용 방식 |
|---|---|---|
| JPG·PNG·GIF·WEBP·BMP | 매직바이트 + 크기 판독 | 배경 이미지 |
| PDF | `pdfinfo`(쪽 수·크기), `pdftotext`(벡터/스캔 추정), 썸네일 | 선택한 쪽마다 별도 도면, 150dpi 래스터 배경. **PDF 내부 선을 CAD 객체로 쓰지 않음** |
| DXF (ASCII) | dxf-parser → 선·폴리라인(벌지 호)·원·호·타원·문자·블록 전개·치수 블록 | 레이어별 표시/숨김·색상, 모델/배치 공간 선택, 단위 확인 |
| DWG | 매직바이트(AC10xx) 확인 → 변환 엔진으로 DXF 변환 → DXF와 동일 처리 | 엔진 미설정 시 "설정 필요" 안내와 DXF·PDF 대안 표시 |

확장자가 아니라 내용으로 형식을 판별하며(가짜 DWG 거부), 미지원 객체·외부참조 누락·CAD 글꼴 대체는 업로드 결과와 "변환 경고·정보"에 표시합니다. 변환은 비동기 작업(`jobs`: 대기·진행·완료·실패)으로 처리합니다. 원본 파일은 수정하지 않고 보관하며 원본 다운로드·개정본 업로드가 가능합니다.

## 5. 저장·동시 편집
- 편집은 메모리에서 즉시 반영 → 변경 목록(dirty) → **5초 자동 저장** 또는 Ctrl+S → `/batch` 트랜잭션.
- 각 객체 `ver` 비교로 다른 사용자가 먼저 수정했으면 전체 저장 거부(409) → "서버 버전 불러오기 / 내 변경으로 덮어쓰기" 선택.
- 저장 실패 시 빨간 안내 + 변경 내용을 브라우저(localStorage)에 임시 보관 → 다시 시도 / JSON 파일로 받기 / 다음 접속 시 복구.
- 15초 간격 접속자 표시, 다른 사용자의 변경 감지 시 자동 반영(미저장 변경이 있으면 안내).
- 모든 변경은 `change_log`에 변경자·시간·사유·전후값 기록.

## 6. 출력
- PDF: 배경(이미지 래스터 / CAD 벡터) + 설계 객체 벡터 + 범례 + 막대 축척 + 도곽(회사 로고, 공사명, 도면명, 도면번호, 축척, 작성일, 개정, 설계·검토·승인). A4~A1, 가로·세로, 영역(전체/현재 화면/지정), 레이어 선택, 컬러·흑백, 선·글자 배율.
  - 지정 축척: `mm/도면단위 = 1000 ÷ (upm × N)`. 표기 "1:N (용지 실제 크기 인쇄 시)", 인쇄 100% 안내. 축척 미설정 도면은 출력 거부.
  - 용지 맞춤: "용지 맞춤(지정 축척 아님)"으로만 표기.
  - 흑백: 선종류(실선·점선·쇄선)와 라벨 접두어(U-, F-, C-, CP-, P-, E-)로 케이블 구분.
- 계통도 PDF, 장비표·물량표 PDF(모든 산출표), 범례표 PDF, 선택 도면 일괄 PDF.
- Excel: 프로젝트 정보 + 16개 표 + (선택) 사용자 입력 단가 내역.
- DXF(R12): 신규 객체 좌표·레이어(CCTV-*)·심볼 BLOCK/INSERT·문자. CAD 배경은 원좌표로 복원, 원본 배경 포함 선택.
- DWG 내보내기: LibreDWG `dwgwrite` 연결 시에만 활성(실험적).
