# 구현 현황과 남은 일

기획서의 원칙대로, 안 된 것을 된 것처럼 적지 않는다.

## 확인 방법

1. **시뮬레이션 테스트** — `DomainTests`가 Unity 없이 게임 규칙 17개 항목을 검증한다.
2. **실행 검증** — GitHub Actions가 리눅스 빌드를 실제로 실행해, 새 게임부터 토네이도 → 조사 → 계약 → 발주 →
   운반 → 시공 → 준공까지 자동으로 진행하고 장면마다 스크린샷을 찍는다. 결과는 `rebuild-city-shots` 브랜치에 올라간다.
   (그래픽 카드가 없는 서버에서 소프트웨어 렌더링으로 실행한다.)

## 확인된 것

### 게임 규칙 (자동 테스트)

- 재난 시드 재현, 피해도 0~100, 같은 재난·같은 틱 중복 피해 차단
- 주택 1채 = 독립 부재 15개(기초, 골조, 외벽 4, 지붕, 창호 4, 현관문, 전기, 배관, 마감). 지붕만 부서지면 벽·창은 그대로
- 공정 선행조건(조사 → 안전구역 → 잔해 제거 → 지붕 철거 → 지붕 설치 → 검측), 조사 전 계약·검측 전 정산 거부
- 자재: 도착 전 설치 불가, 부족하면 가능한 물량까지만, 재고·예약 음수 없음, 할증 10%(20m2 → 22m2)
- 작업자 2명: 한 작업에 한 명, 적치점에서 자재를 들고 작업점으로 이동, 재난 경보 시 대피·자재 반환, 이후 재개
- 플레이어 직접 작업: 현장에서만, 중단해도 완료량 보존
- 품질 = 자재등급×0.35 + 숙련도×0.35 + 공법×0.2 + 검사×0.1. 75 미만이면 재시공
- 원장: 현금 = 원장 합계, 현금 음수 없음, 준공 정산 1회만
- 저장: 체크섬, 임시 파일 후 교체, 백업 복구, 불러온 뒤 결과 동일

### 화면 (실행 검증 스크린샷으로 확인)

- 시작 화면, 한글 글꼴(Pretendard) 표시, 카드형 HUD(자금·시각·단계 표시·배속·현장 패널·직원·자재·원장)
- 3D 마을: 주택 6채(창틀·덧문·현관·처마·굴뚝·화단·울타리), 도로·인도·횡단보도, 가로등, 전신주와 전선,
  사무소, 대피소, 이웃집, 밭, 나무, 산, 구름, 주차된 차
- 토네이도 깔때기와 잔해, 경보 배너, 지붕 타일 파손·철거·설치, 깨진 창, 벽 손상 자국, 잔해
- 계약 후 비계·안전 고깔·공사 안내판, 트럭 운반과 자재 팔레트, 작업자 운반·망치질 동작
- 낮밤 변화(밤에는 가로등·창문 불빛), 그림자, 안개
- 빌드에서 새 게임부터 준공까지 완주(품질 약 86점)

## 빌드는 되지만 직접 확인하지 못한 것

- **Android 실기기**: APK(IL2CPP, ARM64)는 빌드되지만 실제 휴대폰에서 실행해 보지 못했다.
  터치 조작(조이스틱·시점 드래그·버튼), 성능(30FPS 목표), 발열, 화면 비율별 UI 배치는 실기기 확인이 필요하다.
- **Windows**: 빌드만 확인. 실행은 리눅스 빌드로 대신 확인했다(코드는 같다).
- **소리**: 효과음(바람·망치·알림·정산)을 코드로 만들어 넣었지만, 서버에는 소리 장치가 없어 들어 보지 못했다.
- **마우스·키보드 조작감**: 자동 진행은 명령을 직접 호출하므로 실제 입력 경로는 사람이 확인해야 한다.
- **저장·이어하기**: 규칙 테스트는 통과했지만 빌드에서 버튼으로 저장·불러오기를 눌러 보지는 못했다.

## 기획서와 다르게 한 것

- 3D 모델: Blender 원본·Prefab·Animator 대신 코드로 만든 저폴리 모델과 코드 동작. 제작 환경에서 Blender를 쓸 수 없었다.
- 렌더링: URP 대신 내장 렌더 파이프라인 + 자체 정점 색상 셰이더(선형 색 공간).
- UI: uGUI 대신 IMGUI(둥근 카드 직접 그리기). Prefab 없이 코드만으로 동작하게 하려는 선택.
- NPC 이동: NavMesh 대신 목표 지점까지 직선 이동. 건물을 통과해 보일 수 있다.
- 차량: 도로 그래프·A* 대신 정해진 경유점 이동. 트럭 1대.
- 프로젝트 구조: Core·Domain·Application·Infrastructure를 `Assets/Game/Sim` 한 어셈블리로 묶음.

## 아직 없는 것

- 홍수·배수, 상가·학교, 정부 입찰, 경쟁 회사 AI, 도시 회복 지표, 대출·파산
- 튜토리얼 연출, 배경 음악, 다국어(현재 한국어만), 접근성 설정
- 장비 임대·중장비, 창고, 자재 가격 변동
- 클라우드 저장, iOS 빌드, 서명 AAB, 스토어 자료

## 알려진 결함

- 밤(18~08시)에는 작업자가 쉬므로 주택 1채 복구에 게임 시간 약 2일이 걸린다. 10배속으로 2~3분.
- 계약 중 다시 토네이도가 오면 남은 공정을 통째로 다시 짠다(설계변경). 부분 진행된 작업의 진행량 표시는 초기화된다.
- 준공 뒤 남은 자재가 현장에 그대로 남는다.
- 작업자가 비계 위로 올라가지 않고 지상에서 작업 동작을 한다.
