## 외부 설정이 필요한 기능 (코드는 구현됨)
- DWG 업로드: LibreDWG(Docker 이미지 포함) 또는 ODA File Converter. AutoCAD R2000~R2018 저장 DWG 6종 변환 검증
- DWG 내보내기: ODA File Converter 설치 + 관리자 설정 (ODA 라이선스 동의 필요, 이 환경에서 미검증)
- 지도 타일: 기본 OpenStreetMap 공개 타일(대량 사용 불가 정책) → 운영 시 VWorld 키 또는 자체 타일 서버 권장
- PDF 업로드: poppler-utils 설치(Docker 이미지 포함)
- HTTPS·외부 접속 QR: 역방향 프록시 + `COOKIE_SECURE=1`, `PUBLIC_URL`
- 동축 감쇠 계산: 품목 감쇠표 + 프로젝트 설정의 신호별 기준 주파수 입력
- 관로 점유율·전압강하·픽셀 밀도 판정: 프로젝트 설정의 적용 기준값 입력
