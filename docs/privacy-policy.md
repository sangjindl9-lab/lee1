# EUM SECURITY PRO 개인정보 처리방침

(Google Play 판과 홈페이지 배포판에 공통 적용. Google Play 판에는 광고·추적 차단 기능이 없습니다.)

시행일: 2026-11-22 · 운영자: 이음소프트웨어 · 문의: pm999@naver.com

## 1. 처리하는 정보와 목적
| 정보 | 어디에 저장 | 목적 | 외부 전송 |
|---|---|---|---|
| DNS 요청 도메인 (차단된 것만 기록) | 기기 내부 DB | 차단 기록·통계, 오차단 즉시 허용 | 없음 |
| 설치된 앱 목록·권한·서명·APK 해시 | 기기 내부 DB | 악성코드 검사 | 없음 |
| 사용자가 선택한 APK 파일 | 검사 중 임시 파일(검사 후 즉시 삭제) | APK 검사 | 없음 |
| 앱 설정 | 기기 내부 | 기능 동작 | 없음 |

- DNS 질의 자체는 사용자가 선택한 DNS 서버(기본: AdGuard DNS 비필터링 서버 unfiltered.adguard-dns.com)로 전달됩니다. 이는 VPN을 쓰지 않을 때 통신사·Wi-Fi DNS 로 전달되는 것과 같은 성격이며, 운영자는 이 질의를 받지 않습니다.
- 차단 목록과 위협 DB 는 원 출처(GitHub·abuse.ch·AdGuard 등)에서 내려받기만 하며, 이때 일반적인 HTTP 요청 정보(IP 주소 등)가 해당 서버에 전달됩니다.

## 2. VPN 사용
이 앱의 VPN 은 피싱·악성 사이트 차단(홈페이지판은 광고 차단 포함)을 위해 기기 안에서만 동작하는 로컬 VPN 입니다. VPN 에는 가상 DNS 주소만 연결되며 일반 인터넷 트래픽은 VPN 을 거치지 않습니다. HTTPS 내용을 복호화하지 않고, 트래픽을 외부 서버로 보내지 않습니다.

## 3. 보관 기간과 삭제
- 차단 기록·검사 기록: 설정한 기간(7/30/90일, 기본 30일)이 지나면 자동 삭제
- 설정 > 검사·차단 기록 모두 삭제로 즉시 삭제 가능, 앱 삭제 시 모두 삭제
- 클라우드 백업·기기 이전 대상에서 제외

## 4. 제3자 제공·위탁
없음. 광고·분석 SDK 를 포함하지 않습니다.

## 5. 서버 심층 분석 (향후 선택 기능)
현재 버전에는 없습니다. 추가될 경우 사용자가 파일마다 명시적으로 동의한 경우에만 업로드하며, 전송 대상·보관 기간·분석 목적을 업로드 전에 안내합니다.

## 6. 권한
INTERNET, ACCESS_NETWORK_STATE(네트워크 변경 대응), FOREGROUND_SERVICE(_SPECIAL_USE)(VPN 상태 알림), POST_NOTIFICATIONS(검사 결과 알림), QUERY_ALL_PACKAGES(설치 앱 악성코드 검사), BIND_VPN_SERVICE(시스템 VPN 연결용 선언). 저장소 전체 접근 권한은 요청하지 않으며, APK 선택은 시스템 파일 선택기(SAF)를 사용합니다.
