# SS-ERP 사용자 매뉴얼

전체 기능(1~5단계) 기준. 메뉴는 내 역할의 권한에 맞는 것만 보입니다.

---

## 1. 화면 구성

```
┌ 좌측 메뉴 ┬ [회사 ▾] [● 작업 현장 ▾]          [통합 검색 /]  [내 이름] ┐
│           │                                                          │
│ 대시보드   │  화면 제목                              [엑셀] [+ 등록]   │
│ 현장관리   │  ┌ 조건: 상태 · 공종 · 기간 · 검색 ─────────────────┐     │
│ 구매·자재  │  │ 표                                              │     │
│ …         │  │ 합계행                                           │     │
└───────────┴──┴─────────────────────────────────────────────────┴─────┘
```

- **회사 선택**: 여러 회사에 소속된 경우에만 바꿀 수 있습니다. 바꾸면 이전 회사 자료는 화면에서 모두 사라집니다.
- **작업 현장**: 지금 일하는 현장을 고정해 둡니다. 대시보드 위에 바로가기가 생기고, 다음 단계에서는 발주·지출 입력 때 자동으로 채워집니다.
- **즐겨찾기**: 메뉴에 마우스를 올리면 나오는 별을 누르면 맨 위에 고정됩니다.
- **좁은 화면(태블릿·휴대폰)**: 메뉴는 ☰ 버튼, 자주 쓰는 화면은 아래 탭에 있습니다. 표는 카드 형태로 바뀝니다.

### 키보드

| 키 | 동작 |
|---|---|
| `/` 또는 `Ctrl+K` | 통합 검색 (현장·거래처·메뉴) |
| `↑` `↓` `Enter` | 표에서 행 이동·열기 |
| `Ctrl+S` | 입력 화면 저장 |
| `Esc` | 창 닫기 |

### 숫자 읽는 법

- 금액은 원 단위, 오른쪽 정렬, 천 단위 쉼표.
- **빨간 △** 는 음수입니다 (예: 계획 이익이 손실).
- 대시보드의 '미처리' 숫자를 누르면 그 일을 처리하는 화면으로 바로 갑니다.

## 2. 로그인

1. 회사에서 받은 아이디와 비밀번호로 로그인합니다.
2. 처음이거나 관리자가 초기화했다면 새 비밀번호를 정합니다 (10자 이상, 영문 대·소문자·숫자·특수문자 중 3종).
3. 2단계 인증을 켜 두었다면 인증 앱의 6자리 숫자를 입력합니다.

5번 연속 틀리면 15분간 잠깁니다. 30분 동안 아무것도 안 하면 자동 로그아웃됩니다.

**2단계 인증 켜기**: 오른쪽 위 내 이름 > 비밀번호·2단계 인증 > 2단계 인증 설정 → Google Authenticator 등으로 QR 스캔 → 6자리 입력.

## 3. 대시보드

| 영역 | 내용 | 누르면 |
|---|---|---|
| 진행 계약총액 | 예정·진행·중지 현장의 계약총액 (공급가액·부가세) | 진행 현장 목록 |
| 실행예산·계획 이익 | 계약 공급가액 − 실행예산 | |
| 진행 현장 공정 | 공정률 막대와 **기간 경과 눈금**. 눈금이 막대보다 10%p 이상 앞서면 붉게 — 일정보다 늦다는 뜻 | 현장 상세 |
| 공종별 진행 계약 | 전기·정보통신·건축·복합 | 해당 공종 현장 목록 |
| 일정 확인 필요 | 준공예정일 지남(붉은색), 30일 안(주황) | 현장 상세 |
| 월별 계약 체결 | 최근 12개월, 계약일 기준 공급가액 | |

"배정 현장만" 권한인 사람은 자기 현장 숫자만 집계됩니다.

## 4. 현장

### 4.1 현장 등록

**현장관리 > 현장 목록 > 현장 등록**

1. 공사명, 공사구분(전기·정보통신·건축·복합)은 필수입니다.
2. 도급 구분: 원도급 / 하도급 / 공동도급(지분율 필수).
3. **계약 공급가액**을 넣으면 부가세(10%, 원 미만 절사)와 계약총액이 오른쪽 요약에 바로 계산됩니다. 계약서 부가세가 단수 차이로 다르면 "부가세 직접 입력"을 체크하세요 (±10원까지 허용).
4. 실행예산을 넣으면 계획 이익과 이익률이 계산됩니다.
5. 저장하면 공사관리번호(`P26-0001` 형식, 연도별 일련번호)가 자동으로 붙습니다.

금액은 화면이 아니라 서버가 다시 계산해 저장합니다. 화면과 서버 값이 다르면 서버 값이 맞습니다.

### 4.2 현장 상세

- **개요**: 계약 당사자·일정·담당.
- **담당자**: "배정 현장만" 권한인 현장소장·공무담당이 이 현장을 보려면 여기서 지정되어야 합니다.
- **첨부파일**: 계약서·도면·내역서. 끌어 놓기로 올립니다. PDF·이미지·엑셀·워드·한글(hwp)·DWG, 20MB 이하. 확장자만 바꾼 위장 파일은 막힙니다.
- **변경 이력**: 누가 언제 무엇을 바꿨는지 (감사로그 권한 필요).

### 4.3 수정·삭제

다른 사람이 먼저 수정했다면 "다른 사용자가 먼저 수정했습니다" 안내가 나옵니다 — 새로고침 후 다시 수정하세요 (내 변경이 남의 변경을 덮어쓰지 않도록).

삭제는 '예정' 상태 현장만 됩니다. 진행 이후 현장은 상태를 '중지'로 바꿔 관리하세요.

## 5. 거래처

**구매·자재 > 거래처**. 목록에서 행을 누르면 오른쪽에 상세 창이 열립니다.

- 사업자등록번호는 입력하는 즉시 검증번호를 확인합니다. 같은 번호로 이미 등록된 거래처가 있으면 저장되지 않고 기존 거래처를 알려 줍니다.
- **계좌번호**는 암호화되어 저장되고 `110-******-789` 처럼 가려서 보입니다. 수정 권한이 있으면 "원문 보기"로 확인할 수 있으며, 조회 사실이 감사로그에 남습니다.
- 사업자등록증·통장사본은 첨부 탭에 올립니다.

---

## 6. 엑셀 출력

목록 화면의 **엑셀** 버튼. 지금 걸어 둔 조건 그대로 내려받습니다. 금액은 실제 숫자 셀이고 맨 아래 합계는 SUM 수식이라 엑셀에서 바로 다시 계산할 수 있습니다. 출력 기록은 감사로그에 남습니다.

---

## 7. 자재마스터

**구매·자재 > 자재마스터**. 자주 쓰는 자재를 등록해 두면 발주서 품명 칸에서 바로 찾아 넣을 수 있습니다.

- 한꺼번에 등록하려면 **엑셀 대량 등록 → 양식 내려받기**. 채운 파일을 올리면 저장 전에 행마다 신규·갱신·건너뜀·오류를 보여 주고, 오류가 하나라도 있으면 아무것도 저장하지 않습니다.
- 자재 상세 아래 **거래처별 최근 매입단가**는 대표이사 승인된 발주서에서 자동으로 쌓입니다.

## 8. 발주서

### 8.1 작성

**구매·자재 > 발주서 > 발주서 작성**

1. 현장과 거래처를 고릅니다 (입력하면 검색). 작업 현장을 정해 두었다면 미리 채워집니다.
2. 품목표에 입력합니다.
   - **품명 칸에 글자를 넣으면 자재마스터가 뜹니다.** ↑↓ 로 고르고 Enter → 규격·단위·단가가 채워지고 수량 칸으로 이동합니다. 이 거래처에 발주한 적이 있으면 그때 단가가 먼저 나옵니다.
   - **엑셀에서 품명·규격·단위·수량·단가(·비고) 순서로 여러 행을 복사해 품명 칸에 붙여넣으면** 한 번에 들어갑니다.
   - Enter 는 다음 행, 마지막 행에서 Enter 는 새 행입니다.
3. 오른쪽 요약에서 공급가액·부가세·합계와 결재선(담당 → 대표이사)을 확인합니다.
4. **저장하고 대표이사 결재 상신** 또는 **임시저장**(Ctrl+S).

부가세는 과세 품목만, 품목별로 원 미만을 절사해 계산합니다. 화면 숫자는 미리보기이고 저장되는 금액은 서버가 다시 계산합니다.

### 8.2 결재선 지정 (상신할 때)

**결재 상신**을 누르면 결재선 지정 창이 뜹니다. 회사 결재선이 미리 채워져 있으니 그대로 **결재 상신**을 누르면 됩니다. 이 문서만 결재를 한 단계 더 받아야 하면:

1. **최종 승인 앞에 단계 추가** → 단계 이름(예: 검토, 전무)을 쓰고 결재자를 고릅니다. 사람을 고르면 그 사람만, 역할을 고르면 그 역할을 가진 누구나 결재합니다.
2. 화살표로 순서를 바꾸고, 휴지통으로 뺍니다.
3. 아래 결재란 미리보기를 확인하고 **결재 상신**.

최종 승인(발주서는 대표이사)은 바꿀 수 없습니다. 발주서 PDF와 화면의 결재란도 지정한 단계만큼 칸이 늘어납니다. 모든 결재 문서(지급결의·기성·변경계약·하도급·실행예산·세금계산서 발행)에서 같은 방식입니다.

### 8.3 결재 (대표이사)

- 결재할 문서는 **전자결재 > 결재함**(휴대폰은 아래 **결재** 탭)에 쌓이고 빨간 숫자로 표시됩니다.
- 발주서를 열면 맨 위에 결재 패널이 있습니다. **승인 / 보류 / 반려** 중 하나를 누릅니다. 반려는 사유를 꼭 적어야 합니다.
- 승인하면 결재란에 도장이 찍히고, PDF 의 "결재 전" 워터마크가 사라집니다.
- 대표이사 결재는 대표이사 역할을 가진 사람만 할 수 있습니다. 최고관리자도 대신할 수 없습니다.

### 8.4 결재 후

| 하고 싶은 일 | 방법 |
|---|---|
| 거래처에 보내기 | **PDF** 를 내려받아 보낸 뒤 **거래처 전송 표시** |
| 승인된 발주서 고치기 | **변경 재결재** → 사유 입력 → 수정 → 다시 대표이사 결재 (개정번호가 붙습니다) |
| 발주 취소 | **발주 취소** → 사유 입력 (검수가 있으면 검수부터 취소) |
| 올린 결재 거둬들이기 | **결재 회수** (대표이사가 아직 아무것도 하지 않았을 때만) |

## 9. 납품·검수

1. 자재가 도착하면 승인된 발주서에서 **검수 등록**을 누릅니다.
2. 품목마다 **실제로 받은 수량**을 입력합니다. 일부만 왔으면 그만큼만 — 나머지는 잔량으로 남고 발주서는 **부분입고** 상태가 됩니다.
3. 잔량보다 많이 입력하면 저장되지 않습니다.
4. 남은 수량을 더 받지 않기로 했다면 **잔량 종결**, 반품이나 잘못 입력했다면 검수 이력에서 **검수 취소(반품)**.

**구매·자재 > 납품·검수** 에서 전체 검수 내역을 기간별로 봅니다.

## 10. 지급결의 (자금 > 지급결의)

돈을 내보내기 전에 반드시 지급결의를 올리고 결재를 받습니다. **결재가 끝나지 않은 결의는 지급 처리 버튼이 열리지 않습니다.**

1. **지급결의 작성** → 무엇을 지급하는지 고릅니다: 검수한 자재대금, 매입 세금계산서, 하도급 기성·유보금, 노무비, 경비(영수증).
2. 지급 예정일과 받는 사람을 확인하고 상신 → 회계관리자 → 대표이사 결재.
3. 은행에서 실제로 이체한 뒤 **지급 처리** (지급일·계좌 입력). 지급 전표가 자동으로 만들어집니다.
4. 같은 결의를 두 번 지급할 수 없습니다. 잘못 처리했다면 **지급 취소**(사유 필수, 역분개).

ERP는 은행 이체를 직접 실행하지 않습니다.

## 11. 회계 (회계 > 전표·원장·재무제표·월마감)

- 대부분의 전표는 검수·지급·계산서·기성·수금 처리 때 **자동으로** 만들어집니다. 직접 쓸 일은 대체·결산 전표 정도입니다.
- 전표 작성 화면은 차변 합계와 대변 합계가 같아야 저장됩니다.
- 전표는 회계관리자가 **승인**해야 장부에 확정됩니다. 승인 전 전표는 '미승인'으로 대시보드에 표시됩니다.
- 승인한 전표는 고치지 않고 **취소(역분개)** 합니다. 원래 전표와 반대 전표가 모두 남습니다.
- **월마감**한 달에는 전표를 새로 넣거나 고칠 수 없습니다. 마감 취소는 사유를 남깁니다.
- 원장·시산표·재무제표는 기간을 고르고 엑셀로 받을 수 있습니다.

## 12. 실행예산·현장 손익

- **현장관리 > 실행예산**: 원가항목(재료비·노무비·외주비·경비)별 계획 금액. 발주(약정)와 실제 원가가 계획의 90%를 넘으면 노란색, 넘으면 빨간색 경고.
- **현장관리 > 현장 손익**: 계약(최초·변경)·청구 매출·수금·미수·원가·지급·예상 이익을 현장별로.

## 13. 세금계산서

### 13.1 매입 (세금계산서 > 매입 수집·처리)

1. **홈택스 엑셀 올리기**: 홈택스 › 전자세금계산서 › 목록조회 › 매입 목록을 엑셀로 받아 그대로 올립니다. 미리보기에서 새로 들어갈 건수와 이미 있는 건수를 확인하고 등록. 같은 계산서는 두 번 들어가지 않습니다. (연동이 켜져 있으면 **홈택스에서 가져오기** 로 직접 수집)
2. 미처리 계산서를 열면 **같은 거래처의 검수 내역**이 후보로 나옵니다. 맞는 검수를 고르거나 **자동 맞추기**. 금액이 다르면 차이가 붉게 표시됩니다.
3. **처리** → 매입 전표(부가세 대급금/외상매입금). 이 계산서로 바로 **지급결의**를 올릴 수 있습니다.
4. **세금계산서 > 발주·계산서 대사** 에서 발주 → 검수 → 계산서 → 지급이 어디까지 됐는지 한눈에 봅니다.

### 13.2 매출 (세금계산서 > 매출 발행)

1. 기성청구 화면의 **세금계산서 발행** 또는 매출 발행 > 작성.
2. 결재 → 발행. 화면 위에 **테스트 모드** 줄무늬 띠가 보이면 실제로 국세청에 가지 않는 '가상 발행'입니다.
3. 운영 모드 발행은 받는 회사 이름을 한 번 더 입력해야 실행됩니다. 발행 후 국세청 전송 상태를 **상태 새로고침** 으로 확인합니다.

## 14. 문서 스캔 (구매·자재 > 문서 스캔)

발주서·거래명세표·세금계산서·영수증의 사진이나 PDF를 올리면 품목·금액을 읽어 옵니다.

1. **올리기** → 문서 종류 선택 → 인식.
2. 왼쪽 원본과 오른쪽 인식 결과를 비교하며 **틀린 칸을 고칩니다**. 인식 확신이 낮은 줄은 노란색입니다.
3. **확인 후 등록** → 발주서·세금계산서·지급결의(영수증)·현장 첨부로 등록됩니다. 확인 없이 자동 등록되는 일은 없습니다.
4. 같은 파일을 두 번 올리면 알려 줍니다.

## 15. 공사관리

### 15.1 계약·변경계약 (현장관리 > 계약·변경계약)

설계변경 등으로 계약금액이 바뀌면 **변경계약** 을 올립니다. 대표이사 결재가 끝나야 확정 계약금액이 바뀝니다. 최초 계약금액은 그대로 남고, 변경 이력이 차례로 쌓입니다. 증액분은 실행예산 초안으로 가져올 수 있습니다.

### 15.2 기성청구 (매출·기성 > 기성청구)

1. **기성청구 작성** → 현장 선택. 공종별 계약금액·전회 누적이 채워집니다.
2. 공종별 이번 회차 금액을 입력하면 누적 진도율이 옆에 표시됩니다. 누적이 계약금액을 넘으면 붉게 표시되고 저장되지 않습니다.
3. 선급금 공제·유보금이 자동 계산됩니다 (현장 정보의 선급금·유보율 기준).
4. 결재 → 승인되면 매출과 미수금이 잡힙니다. **기성내역서 PDF·엑셀** 로 발주처에 제출합니다.
5. **세금계산서 발행** → **수금 기록**.

### 15.3 수금·미수금 (매출·기성 > 수금·미수금)

현장·발주처별 청구액·수금·미수금·연체. 수금예정일이 지난 금액은 붉게 표시됩니다. 선급금·유보금 수령도 여기서 기록합니다. **기성 승인(매출)과 입금(수금)은 따로** 기록되므로, 청구했지만 못 받은 돈이 미수금으로 남습니다.

### 15.4 하도급 (매출·기성 > 하도급·외주)

협력업체와의 하도급 계약 → 결재 → 하도급 기성(결재) → 지급결의. 변경계약, 유보금 지급, 완료 처리까지 한 화면에서 합니다.

### 15.5 노무 (노무 > 작업일보·노무비)

작업자 등록(주민번호·계좌는 암호화, 원문 보기는 권한이 있어야 하고 기록이 남음) → 날짜별 작업일보(공수·연장) → 기간을 골라 **확정**(노무비 전표) → 지급결의.

### 15.6 준공정산 (현장 상세 > 준공정산)

결재 중인 문서가 남아 있으면 정산할 수 없습니다. 미수금·미지급 등 경고를 확인하고 정산하면 현장이 '정산 완료'가 되어 새 발주·기성을 막습니다. 필요하면 정산을 다시 열 수 있습니다.

## 16. 자금

### 16.1 거래내역 대사 (자금 > 거래내역 대사)

은행·카드사 거래내역을 ERP 기록과 맞춥니다.

1. 인터넷뱅킹·카드사 홈페이지에서 거래내역을 **엑셀(.xlsx) 또는 CSV** 로 받습니다.
2. **거래내역 올리기** → 계좌·카드 선택 → 파일 선택 → 미리보기 확인 → 등록. 이미 올린 거래는 다시 들어가지 않습니다.
3. ERP에 이미 기록된 지급·수금과 금액·날짜(앞뒤 5일)가 맞는 것이 하나뿐이면 **자동으로 연결**됩니다.
4. 남은 **미처리** 거래를 하나씩 눌러 처리합니다:
   - 이미 있는 지급·수금과 **연결**
   - 결재된 지급결의를 이 출금으로 **지급 처리** / 기성 미수금을 이 입금으로 **수금 기록**
   - 수수료·이자처럼 기록이 없는 거래는 상대 계정을 골라 **전표 만들기**
   - 계좌 간 이체 등은 사유를 적고 **제외**
5. 위쪽 계좌 카드에서 **통장 잔액(마지막 거래 잔액)과 장부 잔액**의 차이를 봅니다. 미처리 거래를 다 맞추면 차이가 0이 되어야 합니다.

### 16.2 자금일보·수지 (자금 > 자금일보·수지)

- **자금일보**: 날짜를 고르면 계좌별 전일 잔액·입금·출금·당일 잔액, 그날 입출금 내역, 7일 안 지급·수금 예정.
- **자금수지 전망**: 앞으로 3·6·12개월 동안 받을 기성과 지급할 결의로 월말 잔액을 계산합니다. 잔액이 마이너스인 달은 붉게 — 미리 자금을 마련해야 하는 달입니다.
- 오른쪽 위 **PDF·엑셀** 로 출력합니다.

## 17. 보고서 (보고서)

왼쪽에서 보고서를 고르고 기간·기준일·현장을 정하면 화면에 바로 나옵니다. **용지(A4·A3)와 방향(자동·세로·가로)** 을 고른 뒤 **PDF 보기·PDF 저장·엑셀**. 엑셀은 숫자가 실제 숫자 칸이라 바로 합계·피벗을 쓸 수 있습니다. 내 권한으로 볼 수 있는 보고서만 목록에 나옵니다.

관급공사라면 **현장 등록 > 나라장터에서 불러오기** → 계약일 기간(1개월 이내)·공사명으로 조회 → 계약을 고르면 공사명·발주기관·계약금액·일정이 채워집니다. 공종·발주처 거래처·담당자를 확인하고 저장하세요. (관리자가 외부 연동에서 나라장터 키를 넣어야 쓸 수 있습니다.)
