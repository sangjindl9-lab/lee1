# 노트프로 진행 보고 (2026-11-21)

판정 기준: **완료** = 코드가 있고 빌드됨 · **테스트 완료** = 자동 테스트(에뮬레이터·실제 PostgreSQL)로 확인 · **미구현** · **확인 필요** = 실기기·계정·키 등 사람이 해야 확인 가능.

## 2. 완료(코드·빌드, 자동 테스트 없음 또는 부분)
- 필기: 펜 5종, 필압·기울기, 손떨림 보정, 펜 프리셋, 형광펜, 실행 취소/다시 실행 300단계
- 터치: 펜/손가락 분리, 손바닥 무시(펜 접촉 중·직후·접촉 면적·Android 13 시스템 판정), 확대 민감도·잠금, 페이지 이동 잠금, 한/두 손가락 스크롤, 두 손가락 탭 실행 취소, 확대 UI 고정/자동 숨김
- 노트: 폴더·하위 폴더, 태그, 즐겨찾기, 최근, 휴지통·복원, 복제, 잠금(생체/화면 잠금), 용량, 템플릿 3종, 용지 4종·규격 5종, 무한 페이지
- 멀티윈도우: 2개 창 좌우/상하, 경계 드래그, 같은 노트 두 창(세션 공유로 충돌 없음), 창 사이 필기 복사, 독립 배율·스크롤, 마지막 화면 복원
- 문서: 텍스트 주석, 북마크, 페이지 회전, PDF 병합·범위 내보내기(분할), 이미지·텍스트 파일 가져오기, Word·PPT·Excel·한글 서버 변환, 서명 저장·삽입, 노트 안·전체 글자 검색
- AI: 기기 안 손글씨 인식(한·영, 결과 수정 후 삽입·원본 보존), 문서 OCR(한국어+라틴), AI 요약·회의록·핵심·할 일·학습 요약·퀴즈·번역(10개 언어)·맞춤법·문장 다듬기·문서 Q&A·자연어 검색, AI 결과는 "AI" 표시로 구분
- 녹음: 녹음·일시정지, 녹음 중 쓴 필기를 누르면 그 순간 재생, 녹음 파일 동기화(첨부)
- 계정: 이메일 가입·로그인·비밀번호 재설정, 로그인 기기 관리, 계정 삭제, 데이터 내보내기, 로그아웃 시 미전송 경고·로컬 노트 유지, 다른 계정 전환 시 연결 여부 선택, 비회원 노트 계정 연결
- 클라우드 백업(암호화 파일 업로드·목록·복원), 기기 자동 백업(Android 백업 규칙)
- 관리자 웹(/admin): 대시보드·사용자·구독·결제·저장 공간·동기화·오류·AI 비용·문의·공지·앱 버전·서비스 상태, 역할 3종
- 접근성: 큰 글씨·큰 버튼, 고대비, 다크, 왼손잡이, 삭제 확인, 초보자 안내, 화면 읽기 설명
- 배포 준비: 서명 AAB 빌드(비밀값 넣으면 자동), 개인정보처리방침 초안, 스토어 문서, 서버 Dockerfile(LibreOffice 포함)

## 3. 미구현
- iOS·iPadOS, Windows·macOS·Linux, 웹 앱 (설계만: `core/` 공유 + 플랫폼 입력 어댑터)
- Google·Apple 로그인 화면(서버 API는 있음, 앱 버튼과 클라이언트 ID 없음)
- Play Billing 결제 화면·서버 영수증 검증(권한 시스템만 완료)
- 음성 → 텍스트 변환, 녹음 내용 검색, 녹음 기반 AI 회의록
- 수식·표 구조 인식, 손글씨 인식 피드백 서버 전송
- 이미지 요소(페이지 위에 이미지를 붙이는 기능 — 지금은 이미지 = 한 페이지)
- 일본어·중국어·스페인어·프랑스어·독일어·포르투갈어·아랍어 화면 번역(문구는 모두 리소스로 분리돼 있어 파일만 추가하면 됨, 아랍어 RTL은 supportsRtl 설정됨)
- 동기화 실시간 알림(WebSocket) — 지금은 2분 주기 + 네트워크 재연결 + 수동
- 사용자 템플릿 만들기, 공동 편집
- R8 코드 축소, 녹음 목록 화면

## 4. 확인 필요(사람·계정·실기기)

- 운영 서버: Railway eum-apps 에 notepro-server·Postgres 생성, 주소 https://notepro-server-production.up.railway.app — **저장소 연결(배포 시작)은 권한 승인이 필요해 멈춤**

- 개인정보처리방침·녹음 고지 문구 법률 검토, 국외 이전 고지
