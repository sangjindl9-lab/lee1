설치·연결 안내

PC 프로그램 다운로드 → 설치 → 같은 계정 로그인 → 모바일 앱 실행 → PC 연결 승인 → 파일 탐색

1. 휴대폰 앱 준비

  1. Google Play에서 파일 관리자 2를 설치(또는 업데이트)합니다.
  2. 앱 홈 화면의 PC 연결을 누르고 회원가입 또는 로그인합니다.
  3. 연결 켜기를 눌러 PC가 휴대폰에 접속할 수 있게 합니다. 알림창에 "PC 연결 중"이 표시됩니다.

2. PC 프로그램 설치

  1. 다운로드 페이지에서 설치 파일을 받아 실행합니다.
  2. SmartScreen 경고가 나오면 추가 정보 → 실행을 누릅니다.
  3. 설치 후 파일 관리자 2 PC를 실행하고 휴대폰과 같은 계정으로 로그인합니다.

3. 연결 승인

두 가지 방법이 있습니다.

  • PC에서 요청: PC 프로그램 왼쪽의 휴대폰 이름을 눌러 연결 요청 → 휴대폰에 승인 창이 뜨면 허용할 폴더를 고르고 승인.
  • 연결 코드: 휴대폰 앱 PC 연결 화면에서 연결 코드 만들기(허용 폴더 선택) → 표시된 6자리 숫자를 PC 프로그램에 입력. 코드는 5분간 유효합니다.
같은 계정이라도 휴대폰에서 승인한 폴더만 PC에서 열 수 있습니다. 읽기 전용으로 허용하면 PC에서 복사(다운로드)만 가능합니다.

4. 파일 주고받기

  • PC 프로그램 가운데 목록에서 폴더를 열고, 파일을 선택해 PC로 받기.
  • PC의 파일을 창으로 끌어다 놓거나 휴대폰으로 보내기를 누르면 현재 폴더에 올라갑니다.
  • 아래쪽에 전송 진행률·속도·남은 시간이 표시됩니다.

5. 클라우드 연결 (Google Drive · Dropbox)

휴대폰 앱의 홈 → 클라우드 또는 PC 프로그램 왼쪽의 클라우드 + 연결에서 연결합니다. 브라우저에서 로그인·허용한 뒤 앱으로 돌아오면 자동으로 연결됩니다.

Google Drive에서 '확인하지 않은 앱' 경고가 나올 때

현재 Google 앱 인증 심사 전이라 아래 경고 화면이 나옵니다. 다음 순서로 진행하세요.

  1. Google 계정을 선택합니다.
  2. 'Google에서 확인하지 않은 앱' 화면에서 왼쪽 아래 고급을 누릅니다.
  3. 아래에 나온 파일관리자2(으)로 이동(안전하지 않음)을 누릅니다.
  4. 권한 화면에서 계속을 누릅니다.
  5. '연결되었습니다'가 나오면 앱(또는 PC 프로그램)으로 돌아옵니다.

Google·Dropbox 비밀번호는 저장되지 않습니다. 연결을 해제하면 저장된 접근 권한도 즉시 삭제됩니다.

6. NAS 연결 (시놀로지 · QNAP · ASUSTOR · WebDAV)

휴대폰 앱 홈 → NAS 또는 PC 프로그램 왼쪽 NAS + 추가에서 제조사를 고르고 주소(DDNS 또는 IP), 아이디, 비밀번호를 넣으면 포트와 주소가 자동으로 채워집니다.

  • 시놀로지: 패키지 센터 → WebDAV Server 설치 → HTTPS(5006) 사용. QuickConnect ID는 WebDAV에 쓸 수 없습니다.
  • QNAP: 제어판 → 네트워크 및 파일 서비스 → WebDAV 활성화(HTTPS).
  • ASUSTOR: 서비스 → WebDAV 활성화(SSL 9802).
외부(회사 밖)에서 접속할 때 — 포트 개방은 권장하지 않습니다.
공유기에서 NAS 포트를 인터넷에 열면 전 세계에서 로그인 시도와 공격을 받을 수 있습니다. 대신 NAS 제조사의 VPN 기능(시놀로지 VPN Server, QNAP QVPN Service, ASUSTOR VPN Server)으로 먼저 VPN에 접속한 뒤, 앱에는 내부 주소(예: 192.168.0.10)를 넣어 연결하세요.
보안을 위해 앱은 다음을 지킵니다: ① 암호화 없는 http와 '인증서 확인 안 함'은 내부망 주소에서만 허용 ② 비밀번호는 등록한 NAS 주소(같은 주소·포트·경로)로만 전송, NAS가 다른 주소로 이동을 요청해도 따라가지 않음 ③ NAS 주소를 바꾸면 비밀번호를 다시 입력해야 함.

NAS 비밀번호는 휴대폰의 보안 저장소(PC는 Windows 자격 증명 관리자·macOS 키체인·리눅스 비밀번호 저장소)에만 저장되며 서버로 보내지 않습니다. 파일은 기기와 NAS가 직접 주고받습니다.

연결이 안 될 때

  • 휴대폰 앱의 PC 연결 화면에서 연결이 켜짐인지 확인하세요. 휴대폰이 꺼져 있거나 인터넷이 끊기면 PC에서 "모바일 오프라인"으로 표시됩니다.
  • 절전 모드·배터리 최적화가 연결을 끊을 수 있습니다. 앱 설정에서 배터리 최적화 예외로 지정하세요.
  • 휴대폰과 PC가 같은 계정으로 로그인했는지 확인하세요.
