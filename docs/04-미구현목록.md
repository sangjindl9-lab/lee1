# 미구현·제약 목록 (v0.1.0)

화면에서는 아래 기능을 “2단계/3단계” 또는 안내 문구로 표시하며, 작동하는 것처럼 보이지 않게 했습니다.

## 2단계 예정
| 기능 | 현재 상태 |
|---|---|
| ONVIF 자동 탐색(WS-Discovery) | 미구현. 수동 IP 등록만 가능. 호스트 네트워크 탐색 서비스 필요(설계서 2.2) |
| 25·36분할, 화면 순환 | 미구현(1·4·9·16분할만) |
| PTZ 이동·줌·프리셋 | 미구현. ONVIF 조회 시 PTZ 지원 여부만 표시, 권한 항목만 존재 |
| 실시간 음성 듣기 | 미구현(영상만 요청). AAC 카메라는 Opus 변환 경로가 필요 |
| 예약(요일·시간) 녹화, 이벤트 녹화, 이벤트 전후 녹화, 정책 충돌 처리 | 미구현. 녹화 방식은 끔/연속/수동(기간 지정)만 |
| 카메라 이벤트(모션·탬퍼링·알람 입력) 구독 | 미구현. ONVIF 이벤트 지원 여부만 표시 |
| 이메일·웹훅 알림, 반복 주기 설정 | 미구현. 웹 내부 이벤트 목록·확인·메모만 |
| 북마크·메모 검색 | 미구현 |
| 카메라 단위 접근 권한 | 미구현(현장 단위 + 기능 권한만) |
| 시청용 코덱 변환(H.265→H.264, AAC→Opus) | 미구현. 브라우저 비호환 코덱은 경고만 |
| 대역폭·CPU·메모리 상세 모니터링, 서비스 재시작 이력 화면 | 부분: 하트비트·시작 시각·서비스 시작 이벤트만 |
| 녹화 일정·시스템 설정 화면 | 메뉴만 비활성 표시(보관 정책 설정은 저장장치 화면에 있음) |

## 3단계 예정
| 기능 | 비고 |
|---|---|
| 제조사 드라이버(Hanwha SUNAPI, Hikvision ISAPI, Axis VAPIX, Dahua HTTP API/NetSDK) | 레지스트리에 “미지원(미구현)”으로 등록. 문서·SDK 확보 조건은 지원표 참조 |
| 여러 현장 통합(Edge Agent·VPN), 현장 단절 표시 | 설계만(설계서 2.3) |
| ONVIF Profile G(장치 저장영상 검색·회수), Profile M | 미구현. 지원 여부만 표시 |
| 다중 카메라 동기 재생 | 미구현 |
| AI 분석 모듈(사람·차량·침입·선 넘기) | 미구현. 이벤트 출처 구분(서버/카메라/분석) 필드만 존재 |
| 장애 전환(대체 녹화) | 미구현. 무중단·무손실을 보장하지 않음 |
| NAS 지원 | 미검증. 로컬 디스크 권장 |

## 1단계 범위 내 제약
| 항목 | 내용 |
|---|---|
| MJPEG·RTMP·SRT 입력 | 미지원(코덱 미지원으로 등록 시 거부) |
| RTSPS 시청 | 녹화는 FFmpeg 로 시도 가능(미검증), mediamtx 시청 경로는 인증서 지문 설정이 필요해 생성하지 않음 |
| 녹화 시각 정확도 | 서버 시계 기준 ±1~2초(GOP 길이에 따라). 카메라 시계는 사용하지 않음 |
| 원본 복사 내보내기 | 직전 키프레임부터 시작(결과에 실제 시작 시각 표시). 정확한 구간은 재인코딩 모드 |
| 누락 구간이 있는 내보내기 | 누락 부분을 건너뛰고 이어 붙임(결과 메모에 표시) |
| 강제 로그아웃 시 열린 실시간 영상 | 새 연결은 즉시 거부되나(HLS 요청별 재검증 여부는 mediamtx 실기 확인 필요), 이미 연결된 WebRTC 세션은 mediamtx 관리 API 를 끈 설계상 끊지 못함(창을 닫거나 재연결 시 차단). 토큰 수명 10분 |
| 공간 기준 정리 | 디스크 전체 여유 공간 기준. 다른 데이터가 같은 디스크를 쓰면 녹화가 먼저 삭제됨 → 전용 디스크 권장. 아주 작은 디스크에서는 기준보다 더 많이 삭제될 수 있음 |
| 구간 확정 디스크 쓰기 | 조각화 MP4 → faststart MP4 재다중화로 쓰기량 약 2배 |
| 재색인 시 녹화 종류 | DB 없이 파일만으로 재색인하면 수동 녹화도 “연속”으로 복원 |
| ONVIF | 연동 구현이며 공식 적합성 인증과 무관. HTTPS ONVIF 는 호스트명 검증 때문에 IP 고정을 하지 않음(검사 후 연결 사이 DNS 변경 위험이 낮게 남음) |
| 카메라 동시 세션 | 카메라당 최대 3개(녹화 1 + 시청 서브 1 + 확대 시 메인 1). 세션 한도가 낮은 장비 설정은 미구현 |
| 2단계 인증(OTP) | 미구현 |
